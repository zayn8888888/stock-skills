# 市场热点扫描

## 核心原则

1. **只扫不测**：只回答"当前哪些板块在被资金 + 新闻同时推动"，**不**预测下一个热点。预测远超公开数据能支撑的范围，会变成瞎猜
2. **三重信号交集**：板块上榜至少需要 ① 涨幅榜 ② 资金净流入榜 ③ 新闻 / 社交热度 三者中命中 ≥ 2。单一维度上榜的板块大概率是噪声
3. **候选不是推荐**：板块内 3-5 只候选只是"符合筛选条件的标的"，**不**表达"建议买入"。最终判断必须经 stock-analyzer 八维度复核
4. **拒绝尾端追涨**：同一只票若近 5 日累计涨幅已超板块 + 8pp，自动降权（已过度拉升，性价比下降）
5. **质量阀门优先于性价比**：市值 / 流动性 / 亏损状态的硬阀门先过，PE 分位排序在后。过小票的低 PE 通常是流动性折价，不是机会

## 前置依赖

依赖 **futuapi skill** 调用富途 API。OpenD 未运行时，先提示用户启动 OpenD。脚本路径按 futuapi skill 的查找规则（默认 `skills/futuapi/scripts/`，fallback `/Users/admin/.claude/skills/futuapi/scripts/`）。

新闻热度依赖 **Tavily**（`mcp__plugin_tavily-web-search_tavily-web-search__tavily_search`）。

## 扫描范围

**市场（第一版）**：港股（HK）+ 美股（US）。用户可显式指定单一市场，默认并行扫两个市场并分开出报告。

**A 股 / 新加坡 / 日本**不在第一版范围 —— 资金流分类口径、板块划分、新闻源结构差异较大，留到下个版本。

## 时间窗口

**双窗口**：5 日（短期动量）+ 10 日（持续性验证）

| 窗口 | 用途 | 出现矛盾时怎么读 |
|------|------|-----------------|
| 5 日 | 抓刚启动 / 加速中的热度 | 5 日强但 10 日弱 → 新热度（机会 + 风险并存） |
| 10 日 | 过滤"一天爆发就哑火"的伪热度 | 10 日强但 5 日弱 → 热度在衰竭（追涨陷阱） |
| 两者都强 | 持续性确认 | 最有信号价值的组合 |

## 扫描流程（4 层漏斗）

```
L1 板块热度三重信号 → 每市场 Top 5 板块
     ↓
L2 热度质量验证 → 持续性 / 集中度 / 催化
     ↓
L3 板块内候选性价比向量 → 每板块 3-5 候选
     ↓
L4 收敛 → 总 3-5 个最终候选 + 衔接 stock-analyzer
```

### L1 板块热度扫描（三重信号）

目标：对每个市场分别产出 Top 5 "热度板块"。

#### 信号 A：板块涨幅榜（5 日 + 10 日双窗口）

```bash
# 1. 拉取市场行业板块列表（按市场分别跑）
python3 skills/futuapi/scripts/quote/get_plate_list.py HK --type INDUSTRY --json
python3 skills/futuapi/scripts/quote/get_plate_list.py US --type INDUSTRY --json
```

对每个板块算 **板块指数 5 日 / 10 日涨跌幅**。可直接取板块自带的 `change_rate_5d / change_rate_10d`（如果 API 没返回，用板块内成分股市值加权计算；见 [references/plate-index-calc.md](references/plate-index-calc.md)）。

取 **5 日涨幅 Top 15 + 10 日涨幅 Top 15 的并集**。

#### 信号 B：板块资金净流入榜

对 A 榜里每个板块，拉成分股当日资金流，按板块聚合：

```bash
python3 skills/futuapi/scripts/quote/get_plate_stock.py <PLATE_CODE> --limit 50 --json
# 并行对成分股（只取前 30 大市值）拉 capital_flow
python3 skills/futuapi/scripts/quote/get_capital_flow.py <STOCK_CODE> --period INTRADAY --json
```

**聚合口径**：板块资金净流入 = Σ 成分股（主力净流入）× 成分股市值权重。取 Top 15。

> 注意：富途 `get_capital_flow` 返回逐分钟数据，累计到当日收盘即日净流入。多日累计需循环拉多天数据。预算有限时只跑"当日 + 5 日"两个口径。

#### 信号 C：板块新闻 / 社交热度

对 A 榜里每个板块，用 Tavily 打 3 条并行 query：

```
并行：
query1: "<板块中文名 + 英文名> 5月 2026" topic=news days=7 → 看官方消息密度
query2: "<板块关键词> 领涨 资金涌入 2026" topic=general days=5 → 看舆论发酵
query3: "<板块英文名> sector rotation rally 2026" topic=news days=7 → 英文主流看法
```

按 `max_results=5`，统计近 7 日相关新闻**条数** + **是否出现"领涨 / 主线 / rally / rotation / outperform"等主题词**。取 Top 10。

#### 信号交集

板块只有在 **A / B / C 三者命中 ≥ 2** 时才进入 L2。命中 1 个的板块扔进附录"单一信号候补"，不进主报告。

### L2 热度质量验证

对 L1 选出的 Top 板块，逐个回答三个问题：

| 质量维度 | 怎么看 | 判断标准 |
|----------|--------|----------|
| **持续性** | 5 日 + 10 日涨幅同向？资金流是否连续 ≥ 3 日净流入？ | 双窗口同向 + 资金连续 → 强信号；单窗口 / 资金断续 → 弱信号 |
| **集中度** | 涨幅 / 成交量集中在几只头部？ | 前 3 只占板块成交 >50% → 龙头行情，跟风票风险大；分散在 10+ 只 → 板块广度好 |
| **催化** | 近 7 日有无财报 / 政策 / 订单 / 监管 / 产品事件？ | 有明确催化 → 可讲故事；纯资金推无基本面 → 纯情绪轮动 |

报告里每个上榜板块都必须标注这三项。

### L3 板块内候选性价比向量

对每个上榜板块的成分股（前 30 市值），打 4 分制的「性价比向量」。**质量阀门先过，再比性价比**。

#### 质量阀门（硬条件，不过直接剔除）

- **流动性**：5 日平均成交额 HK ≥ 2000 万港币 / US ≥ 300 万美元
- **市值**：HK ≥ 30 亿港币 / US ≥ 5 亿美元（小市值噪声 > 信号）
- **亏损状态**：PE-TTM 为负 → 本轮不考虑（亏损股的估值分位无意义）
- **停牌 / 新股**：上市不足 60 日的跳过
- **仙股**：股价 < HK$1 / < US$3 跳过

#### 性价比向量（软排序）

```bash
python3 skills/futuapi/scripts/quote/get_stock_info.py <CODE> --json
python3 skills/futuapi/scripts/quote/get_kline.py <CODE> --ktype 1d --num 60 --json  # 算 PE 分位 / 动量需要
python3 skills/futuapi/scripts/quote/get_capital_flow.py <CODE> --json
```

| 因子 | 口径 | 打分 |
|------|------|------|
| **PE 分位** | 近 60 日 PE-TTM 在自身历史的百分位 | <30% → +2，30-50% → +1，50-70% → 0，>70% → -1 |
| **相对板块动量** | 近 5 日涨幅 − 板块 5 日涨幅 | <-5pp → +2（板块涨它没涨，追赶空间）；-5~+3pp → +1；+3~+8pp → 0；>+8pp → -2（已过度拉升） |
| **资金流** | 近 3 日主力资金净流入 / 总成交 | >5% → +2；1-5% → +1；-1~1% → 0；<-1% → -1 |
| **业绩质量** | EPS 为正 + 股息率 > 0 + 52 周不处历史高点 ±5% | 同时满足 → +1，否则 0 |

**总分 ≥ 4 进候选**。每板块取总分最高的 **3-5 只**。

### L4 收敛

把各板块 L3 候选合并、去重（跨板块标的只保留一次），按总分排序取 **Top 3-5**，作为建议交给 stock-analyzer 深度分析的最终清单。

**衔接**：报告末尾明确说：「建议对下列候选调用 stock-analyzer 做八维度深度分析：`stock-analyzer 分析 <CODE1>, <CODE2>, ...`」，让用户一键进入下一步。

## 常见陷阱

详细见 [references/pitfalls.md](references/pitfalls.md)。速记：

- **板块划分偏差**：富途的 INDUSTRY 分类和主流 GICS 不完全一致，某只票可能被放在"非主业"板块里（如富途归在"资本市场"但该板块大多是加密币公司）。遇到"板块代表性差"时，换 CONCEPT 类板块再扫一次
- **资金流单日不够**：单日主力净流入可能是当日事件性买入，**必看 3-5 日累计**
- **新闻热度 ≠ 催化**：有可能只是媒体集中炒冷饭（尤其是英文财经 RSS 循环转载）。query 里要求关键词带"领涨 / rally / outperform"这类强势表述，避免把"XX 板块风险"这类看空新闻当正面热度
- **个股权重畸形**：板块内如果某 1-2 只权重超 40%（如港股"资本市场"板块有腾讯），板块涨跌几乎等于这几只票的涨跌，信号质量差。L2 集中度检查要把这种情况标出来
- **港股与美股信号不通用**：港股常用"南向资金 / 港股通持股变动"做配套指标，美股常用"13F / SPDR ETF 资金流"。第一版不细分，但报告里若发现南向 / ETF 数据能补强，单独标注
- **PE 分位窗口短**：60 日分位在极端行情里会失真。若板块刚经历系统性杀跌或爆涨，PE 分位应配合 60 日 / 250 日 两档一起看（250 日需拉更多 K 线）
- **不要把"跌多了"当性价比**：一只票 PE 分位 20%、相对板块跑输 10pp，也可能是基本面恶化而非机会。必须过 L3 的质量阀门（EPS 为正、非 52 周新低边缘）

## 什么时候答"不确定"

明确告诉用户**无法给出热点清单**，不要硬凑：

- OpenD 未连接 / 板块列表接口失败
- 当日是节假日 / 半日市（数据信号不足 1 个完整交易日）
- Tavily 配额被打满，新闻维度缺失 → 只给 A+B 双信号板块，但标注"新闻维度缺失"
- 单一市场全部板块 5 日涨幅都为负（系统性杀跌行情）→ 明确说"当前市场无热点板块，属防御行情，下一步更适合看避险 / 低波板块"而非强行推候选

## 输出调性

- **中性描述**："XX 板块近 5 日涨 +X%，资金净流入 X 亿，媒体集中报道 Y 事件" —— 不说"板块启动 / 主升浪 / 风口"
- **候选措辞**："符合性价比向量筛选的候选"而不是"值得关注的标的 / 优质标的"
- 不出"下一个热点是 XX"的结论。**只描述当前，衔接到 stock-analyzer 做深度验证**
- 候选代码用反引号包裹，方便用户复制给 stock-analyzer
