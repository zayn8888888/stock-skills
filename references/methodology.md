# 分析方法论详解

本文档补充 SKILL.md 的七维度流程，提供每个维度**如何组织判断逻辑**的具体方法。

## 维度 1：行情速览 —— 锚定时空坐标

目的：让用户快速抓到"现在在哪里"。

必答三个问题：

1. **位置**：现价处于 52 周高/中/低位？距 52 周高/低点多少百分比？
2. **波动**：今日振幅是否异常放大（对比近 30 日平均振幅）？
3. **量能**：今日成交额相比近 5 日平均是放量还是缩量？放量多少倍？

**语言模板**：
> 现价 XX.XX，<涨/跌> X.XX%，成交额 X.X 亿（较 5 日均值 <放量 N 倍 / 缩量 N%>）。位于 52 周 <高/中/低> 位，距高点 -X%，距低点 +X%。

## 维度 2：技术面 —— 趋势、位置、量价

核心关注点，按优先级：

1. **趋势方向**：30 日 K 线整体是上升 / 下降 / 震荡？
2. **关键位**：近期支撑位（前低 / 整数关口 / 均线）、阻力位（前高 / 整数关口）
3. **量价配合**：上涨是否放量？下跌是否放量？（放量下跌是危险信号）
4. **破位信号**：是否跌破关键支撑？是否站上关键阻力？

**判断规则**：
- 连续 5 日以上在 5 日均线上方 = 短期强势
- 跌破 20 日均线且 20 日均线拐头向下 = 中期走弱
- 创 52 周新低 = 明确弱势，不轻言抄底

## 维度 3：估值水平 —— 绝对 + 相对 + 历史

不要只看绝对 PE / PB 数值，必须做三重对比：

1. **绝对水位**：PE-TTM 是多少？是否极端（<10 或 >50）？
2. **历史分位**：当前 PE 在过去 3-5 年历史的分位（需另查，Futu API 不直接提供，可用 Tavily 查"<股票> PE 历史分位"）
3. **行业对比**：与同行 PE/PB 谁高谁低？（见维度 6）

**股息率解读**：
- 稳定高股息（3 年以上 >3%）= 红利属性
- 突然飙升的高股息（股价大跌推高）= 股息率陷阱，要警惕基本面问题
- 近期有大额回购承诺 = 类分红，可以加分

## 维度 4：资金面 —— 谁在买谁在卖

资金流向要分层看：

| 资金类型 | 代表 | 判断意义 |
|---------|------|---------|
| 超大单 | 机构 / 游资 | 主力动向 |
| 大单 | 中等机构 / 大户 | 准主力 |
| 中单 | 小户 / 程序化 | 跟风盘 |
| 小单 | 散户 | 情绪盘 |

**判断规则**：
- 主力（超大+大单）净流入 + 股价上涨 = 健康上涨
- 主力净流出 + 股价上涨 = 散户接盘，警惕
- 主力净流入 + 股价下跌 = 主力低吸，可能止跌
- 主力净流出 + 股价下跌 = 主跌浪，不要接

**陷阱警示**：单日数据偶然性大，必须看 3-5 日趋势。如果 Futu 当日分钟级数据不够，应明确告诉用户"仅代表当日"。

## 维度 5：盘口情绪 —— 短线温度计

盘口数据时效性极强（5 分钟后就可能反转），只作为**即时情绪**参考。

**买卖盘深度**：
- 买盘 10 档累计 > 卖盘 10 档累计 = 短线多方占优
- 反之空方占优
- 差距 < 10% 视为均衡

**逐笔成交方向**：
- 近 30 笔主动买单占比 > 60% = 短线买方强
- < 40% = 短线卖方强
- 40-60% = 多空拉锯

**注意**：盘口挂单可以撤单，大单挂单可能是诱多/诱空陷阱。**逐笔成交是真金白银**，可信度高于挂单。

## 维度 6：同行对比 —— 横向定位

为什么必做：单看一只股票的 PE 20 倍无法判断高低，必须放到同行里。

**选同行的标准**：
1. 业务高度相似（主营重合度 >60%）
2. 市值量级相近（相差 1 个数量级以内）
3. 市场相同（A 股和港股直接对比 PE 有误导）

**对比表必含字段**：
| 代码 | 名称 | 现价涨跌 | PE-TTM | PB | 股息率 | 市值 |

**结论语言模板**：
> 相比 <同行 A>（PE XX）和 <同行 B>（PE XX），<标的>PE XX 处于 <高/中/低> 位，<溢价/折价> X%。

## 维度 7：新闻与事件 —— 补齐基本面

富途 API **不提供** 公司公告、财报摘要、北向资金、机构评级等数据，必须用 Tavily 补充。

**搜索优先级**：
1. 最近财报日期 + 核心数据（营收 / 净利润 / 毛利率 YoY）
2. 近 30 天重大公告（回购 / 分红 / 高管变动 / 诉讼）
3. 所属行业最新政策和竞品动态
4. 北向 / 机构持仓变化（如果是 A 股 / 港股通标的）

**搜索技巧**：
- 中文公司名比 Ticker 搜出来的新闻更全
- `days: 30` 限制近期新闻，避免旧信息
- `topic: "news"` 优先财经新闻而非通用网页

## 综合研判的组织逻辑

把七个维度的输出**结构化**为用户能下决策的材料：

### 利多因素
从 7 个维度抽取正面信号，每条**带数据**：
- 不要说"估值便宜"，要说"PE-TTM 15 倍，低于同行平均 22 倍"
- 不要说"主力进场"，要说"今日主力净流入 3.6 亿，占成交额 12%"

### 利空因素
对称地抽取负面信号，同样带数据。

### 风险提示
列出**还没发生但可能触发下跌的事件**：
- 未明朗的管理层变动
- 即将披露的财报风险
- 行业政策不确定性
- 技术破位可能引发的程序化卖盘

### 关键信号（拐点确认）
用户问"能不能抄底 / 是否利空出尽"时必答：**要看到什么信号才能确认安全**？
- 股价放量收复关键均线
- 主力资金连续 3 日净流入
- 重大不确定性落地（如高管任命 / 财报披露）
- 同行板块联动回暖

**关键原则**：不直接给买卖建议，而是给"观察清单"，把判断权交回用户。
