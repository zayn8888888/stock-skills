## 估值指标

### PE-TTM（滚动市盈率）

**计算**：当前股价 / 最近 12 个月每股收益

**正常解读**：
- < 10：低估（但要看是否是周期股底部）
- 10-20：合理（消费 / 金融常见）
- 20-40：成长溢价（科技股常见）
- > 40：高估或高成长预期

**陷阱**：

1. **周期股倒置**：钢铁、煤炭、航运等周期股，盈利高峰时 PE 反而最低（看起来便宜但实际见顶），盈利低谷时 PE 很高或为负（看起来贵但可能是底部）。
2. **会计差错更正**：公司追溯调整过往利润（典型案例：五粮液 2025 年追溯调整），会导致 TTM 盈利数字被拉低，PE 被动抬高，并非真实估值变化。
3. **一次性损益**：变卖资产、税收返还等一次性收益会推高 TTM 盈利、拉低 PE，需剔除后再看。
4. **亏损股无 PE**：亏损公司 PE 为负或不显示，不能用 PE 评估，改用 PS / PB。

### PB（市净率）

**适用**：金融股、周期股、重资产公司

**警惕**：
- PB < 1 不等于便宜，可能是市场预期净资产贬值（比如地产存货减值）
- 科技 / 消费股 PB 高是常态，因为品牌、专利等无形资产未完全反映

### 股息率（Dividend Yield）

**正常解读**：
- < 1%：成长股 / 不派息
- 1-3%：平均水平
- 3-5%：红利型
- > 5%：高股息（需验证稳定性）

**陷阱**：

1. **股息率陷阱**：股价腰斩会让股息率看似翻倍，但如果公司盈利恶化，下一年可能大幅减派。必须看近 3 年派息是否稳定。
2. **一次性特别分红**：某些公司剥离资产后一次性大派息，不可持续。
3. **承诺 ≠ 兑现**：管理层公告的回购分红计划要看实际执行进度，不能把"计划金额 / 市值"当股息率。

### 52 周高低位

提供价格位置感：
- 距 52 周高点 -30% 以上 = 明显调整
- 创 52 周新低 = 弱势明确，不要接飞刀
- 临近 52 周高点 = 接近阻力，突破需放量确认

## 资金流向指标

富途 API 提供的资金流向基于**成交单大小分档**：

| 档位 | 成交金额阈值（A 股） |
|------|---------------------|
| 超大单 | > 100 万 |
| 大单 | 20-100 万 |
| 中单 | 4-20 万 |
| 小单 | < 4 万 |

美股 / 港股阈值不同，接口返回的都是统一分类。

### 主力资金（超大单 + 大单）

**判断规则**：
- 净流入：主力在买入（但要区分是建仓还是掩护出货）
- 净流出：主力在卖出（可能是获利了结或看空）

### 陷阱

1. **单日偶然性**：某个机构调仓可能一天砸 5 亿，不代表趋势。看 3-5 日累积。
2. **T+0 伪信号（美股/港股）**：高频量化做市商可能同时挂大买大卖，净流向看似剧烈波动实为中性。
3. **期权 / 融券对冲**：看涨期权买方可能同时融券卖出正股对冲，资金流出不代表看空。
4. **接力 vs 接盘**：主力卖出、散户接盘，短期可能仍上涨（散户情绪推动），但中期大概率回落。

## 盘口与成交指标

### 买卖盘深度

**读法**：
- 买 1-10 档累计挂单量 vs 卖 1-10 档累计挂单量
- 差距 > 30% 才视为明显偏向

### 陷阱

1. **撤单成本低**：A 股撤单免费，大额挂单可能是诱多/诱空，几秒内就能撤。
2. **冰山单**：机构只露出一部分挂单，看到的盘口不是全貌。
3. **开盘集合竞价特殊**：集合竞价阶段的"虚盘"不代表实际意愿。

### 逐笔成交方向

比挂单**可信度高得多**，因为是真金白银成交。

**读法**：
- 按成交时买卖价判定方向（买一价成交 = SELL 主动，卖一价成交 = BUY 主动）
- 近 30 笔 BUY 方向占比 > 60% = 短线买方强
- < 40% = 短线卖方强

**陷阱**：大单 BUY 可能是机构被迫扫货（如期权行权交割），不代表基本面观点。

## 技术指标

### K 线与均线

**常用均线**：
- MA5 / MA10：短期趋势
- MA20 / MA60：中期趋势
- MA120 / MA250：长期趋势

**判断规则**：
- 股价在所有均线之上 + 均线多头排列 = 强趋势
- 股价跌破 MA20 且 MA20 拐头 = 短期转弱
- MA5 下穿 MA20（死叉） = 短期空头信号（但要量能确认）

### 量价关系

**健康信号**：
- 上涨放量：主力推动
- 下跌缩量：抛压减轻

**危险信号**：
- 上涨缩量：乏力，可能滞涨
- 下跌放量：恐慌盘出逃
- 高位巨量滞涨：见顶信号

### 支撑阻力位

**常见支撑**：
- 前期整数关口（如 100、50）
- 近 N 日均线
- 历史成交密集区
- 前期重要低点

**重要**：不要迷信单一支撑位，要看量能是否配合。无量破位 = 短期诱空；放量破位 = 趋势改变。

## 应用口诀

- **便宜不等于值得买**：PE 低可能是周期见顶或基本面恶化
- **贵不等于要卖**：高 PE 可能是高增长兑现
- **资金流向只是滞后指标**：等它明朗时行情已走过半
- **盘口看情绪，K 线看结构，新闻看预期，同行看定位**
