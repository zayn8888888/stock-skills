# 加密资产指标解读指南

## 行情基础指标

### 市值 vs FDV
- **市值（Market Cap）** = 流通量 × 当前价
- **FDV（Fully Diluted Valuation）** = 总量 × 当前价
- FDV/市值 > 3x → 警惕大量未解锁代币抛压；< 1.5x 为健康区间

### 流通比（流通量÷总量）
| 比值 | 含义 |
|---|---|
| > 80% | 大部分已流通，解锁抛压小 |
| 50-80% | 中等，需关注解锁时间表 |
| < 50% | 大量待释放，高稀释风险 |

### ATH 距离
- 距 ATH > 70% → 深度腰斩，熊市中期或早期恢复
- 距 ATH 30-70% → 仍在修复过程
- 距 ATH < 30% → 接近历史高点，突破难度大

## 技术面指标

### RSI（14日）
| RSI | 解读 |
|---|---|
| > 70 | 超买，短期回调压力 |
| 50-70 | 强势区间 |
| 30-50 | 弱势未超卖 |
| < 30 | 超卖，可能技术反弹 |

### 均线系统
- 7日均价 > 30日均价 → 短期趋势向上（金叉）
- 7日均价 < 30日均价 → 短期趋势向下（死叉）

### 成交量异常倍数（24h量 ÷ 7日日均）
- > 2x → 异常放量，关注方向是否配合价格
- 价格新高+放量 → 趋势确认；跌破支撑+放量 → 趋势加速

## 链上指标（Hyperliquid）

### Funding Rate（年化 APR）
资金费率 > 0 代表多头向空头支付，反映多头拥挤度：

| APR | 信号 |
|---|---|
| < 0% | 空头拥挤，可能轧空 |
| 0-20% | 正常，多空均衡 |
| 20-100% | 多头开始过热 |
| > 100% | 极度多头拥挤，反转风险高 |
| > 200% | 历史极端值 |

### 链上 OI（未平仓合约）
- OI 上升 + 价格上涨 → 新资金入场，趋势健康
- OI 上升 + 价格横盘 → 多空博弈，等待方向
- OI 急速下降 → 多头爆仓或主动离场，可能触底

### 链上溢价（链上价 vs 现货）
- 正溢价 → 链上情绪偏多
- 负溢价 → 链上情绪偏空，可能领先现货下跌

## 赛道相对动量

**超额收益 = 本币 7d/30d 涨跌幅 - 赛道均值**

| 超额收益 | 解读 |
|---|---|
| > +30pp | 赛道内强势领涨，短期可能透支 |
| +10 ~ +30pp | 赛道内跑赢，叙事优势明显 |
| -10 ~ +10pp | 跟随赛道走势 |
| < -10pp | 赛道内落后，补涨机会或基本面弱 |

| 强度 | 特征 |
