# 常见陷阱速查

## 通用陷阱

| 陷阱 | 说明 | 解决 |
|------|------|------|
| **INDUSTRY 漏主题** | 纯行业划分里没有 AI 产业链 / HBM / 存储 / 核聚变 / 创新药链等跨行业主题 | 必须并扫 CONCEPT |
| **今日涨幅误导** | 当日大票回调会让板块指数转负，但 5-10 日累计仍强势 | 必须用双窗口并集，严禁以今日涨幅作为筛选口径 |
| **板块指数骗人** | 市值加权让 1-2 只权重股决定板块涨跌 | 必须用成分股 5d 涨幅中位数校验，背离 >5pp 直接标"权重法伪信号" |
| **集中度 = 单票行情** | Top1 >50% 的板块本质是那只股在动，不是板块行情 | 直接走 stock-analyzer，不做板块分析 |
| **资金流单日不够** | 单日主力净流入可能是事件性买入 | **必看 3-5 日累计** |
| **新闻热度 ≠ 催化** | 英文 RSS 会循环转载，纯热度不等于利好 | query 里要求关键词带"rally / outperform / 领涨"等强势表述；负面词要反向扣分 |
| **PE 分位窗口短** | 60 日分位在极端行情失真 | 板块若刚经历系统性杀跌或爆涨，PE 分位应配合 60 日 / 250 日两档一起看 |
| **"跌多了 ≠ 便宜"** | PE 分位 20% + 跑输板块 10pp 可能是基本面恶化 | 必须过硬阀门（EPS 为正、非 52 周新低边缘） |
| **港股与美股信号不通用** | 港股看南向资金/港股通持股变动，美股看 13F / SPDR ETF 资金流 | 发现补强数据就单独标注，不混用 |

## 东方财富 API 专属陷阱

| 陷阱 | 说明 | 解决 |
|------|------|------|
| **节点不稳定** | `push2.eastmoney.com` 频繁 502；`push2his.eastmoney.com` 高频调用后限流 | 优先用 `push2delay.eastmoney.com`；历史 K 线加 0.3s 间隔或换时段重试 |
| **噪音板块污染排行** | 「昨日涨停」「历史新高」「连板」等统计类板块常驻 5d 排行 Top 10 | 进 L1.5 前必须用 `NOISE_KEYWORDS` 过滤（完整列表见 [api-eastmoney.md](api-eastmoney.md)） |
| **f115 不是 10 日涨幅** | `f115` 字段实测约为 30 日或更长涨幅，不是 10 日 | 10 日涨幅需通过富途 `request_history_kline` 计算 |
| **f104/f105 在成分股接口无效** | `fs=b:BKxxxx` 接口里 f104/f105 返回 0 | 成分股 5 日涨幅用 **f109**；f104/f105 只在板块列表接口（`fs=m:90+t:3`）有效 |
| **市场标识混淆** | `f13=1` → SH；`f13=0` → SZ | 转换为富途代码：`f"{'SH' if f13==1 else 'SZ'}.{f12}"` |
| **单次最多 100 条** | pz 设多少都只返回 100 | 486 个板块要分 5 页（pn=1~5） |
| **美股蓝筹资金流返回 0** | `get_capital_flow` 对头部股不全 | 启用"成交 × 涨幅"代理，不要因为返回 0 就判"无资金"（详见 [api-futu.md](api-futu.md)） |
| **PE 字段跨源不一致** | snapshot 的 `pe_ratio` 在港股常为 null | 首选 `get_stock_info` 的 `pe_ttm` |

## A 股专属陷阱

| 陷阱 | 说明 | 解决 |
|------|------|------|
| **涨跌停扭曲当日涨幅** | A 股 ±10% 日限（科创板 ±20%）导致"今日涨幅=10%"无法判断真实需求强度 | 必须用 5 日 / 10 日累计涨幅；严禁以单日涨停当超强信号 |
| **ST 股异常拉升** | ST/*ST 股常因借壳预期出现异常涨停，涨幅榜排名极高但属噪音 | 质量阀门里硬过滤，名称含 ST 直接剔除 |
| **概念炒作周期极短** | A 股概念板块平均热度持续 3-7 个交易日后衰减 | L5 外推里的⑧类情绪传导窗口极窄，报告中必须标注时效 |
| **T+1 追涨成本高** | 当日买入被套后无法当日止损 | 候选排序时对「已处于短线高位 + 近 1 日大幅放量」的个股额外降权 |
| **北向资金延迟披露** | 沪深港通北向资金数据有延迟（T 日收盘后公布） | Tavily 抓到的可能是昨日数据，需在报告中标注数据时点 |
| **限售股解禁** | 大股东限售股解禁是 A 股特有负催化 | 候选标的若近 30 日内有大额解禁，在候选备注里标注（Tavily 查询「<股票名> 限售股解禁 日期」） |
| **A 股无做空机制** | 融券门槛高，空头噪音少但泡沫更容易积累 | L2 集中度门槛比 HK/US 更需严格执行 |
