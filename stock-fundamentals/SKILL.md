# 自下而上基本面研究

## 前置依赖

- **富途行情**：依赖 `futuapi` skill 的报价脚本（需 OpenD）。下文命令示例为 `python3 skills/futuapi/scripts/...`，请替换为你本地 futuapi 实际目录（与 [`stock-analyzer`](../stock-analyzer/SKILL.md) 约定一致）。
- **近期新闻**：在四步分析开始前调用 `futu-stock-digest` skill，扫描近 7 天重要新闻（无需 OpenD）。
- **财务与定性信息**：Tavily 等搜索工具，用于补充营收、ROIC、竞争与风险等（与下文查询模板配合）。

## 核心原则

1. **证伪优先**：每个正面结论都要主动寻找反驳证据，不替用户做投资决策
2. **区分事实与推断**：财务数据是事实，护城河强弱是判断，估值是模型——三者要清晰分开
3. **会计陷阱警惕**：GAAP 数字不等于经济现实，调整口径必须说明
4. **苏格拉底式引导**：如果用户正在学习基本面分析，通过提问引导推导，而非直接给答案

## 适用场景

- 用户说"帮我研究/分析 XXX 基本面"
- 用户问"XXX 护城河在哪里"、"XXX 值不值得长期持有"
- 用户给出一只股票代码，没有特定交易意图，想了解公司本质

| 盈利预警 / 上调 | 更新正常化 FCF 估算 | Step 4 估值 |

## 四步分析框架

---

### Step 1：商业模式（Business Model）

**目标**：搞清楚公司靠什么赚钱，钱从哪里来，谁付的钱。

必须回答的三个问题：

1. **收入来源**：主要产品/服务是什么？谁是付钱的客户？
2. **成本结构**：主要成本是什么？是重资产还是轻资产？
3. **利润来源**：毛利率大概在什么水平？为什么能有这个利润率？

**警示信号**：
- 收入来源超过 3 个且每个都不超过 20% → 复杂度高，谨慎
- 单一大客户占比 > 30% → 客户集中风险
- 毛利率低于 20% → 通常难有护城河（商品化竞争）

---

### Step 2：护城河识别（Economic Moat）

**五类护城河（按持久性排序）**：

| 类型 | 核心问题 | 典型案例 |
|------|---------|---------|
| 1. 无形资产（品牌/专利/监管牌照） | 客户会为品牌溢价多付钱吗？专利还有多少年？ | KO、LLY |
| 2. 切换成本 | 换掉这家公司的代价有多高？ | MSFT（Office）、V/MA |
| 3. 网络效应 | 用户越多，产品越有价值吗？ | META、VISA |
| 4. 成本优势 | 它能比竞争对手更便宜地提供同样服务吗？ | COST、WMT |
| 5. 有效规模 | 市场够小让竞争对手没兴趣进入吗？ | 专业工业气体、小型网络运营商 |

**护城河宽窄判断**（结合财务验证）：
- **宽护城河**：ROIC > 15%，且 10 年内持续，竞争对手无法复制
- **窄护城河**：ROIC 10-15%，有部分优势但可侵蚀
- **无护城河**：ROIC < 10%，靠行业周期而非竞争优势赚钱

**必问的反驳问题**：
- 护城河是真实的还是暂时的行业顺风？
- 过去 5 年市场份额有没有被侵蚀？
- 谁是最有可能颠覆它的竞争对手？为什么还没成功？

---

### Step 3：财务验证（Financial Verification）

**目标**：用数字验证护城河叙述是否真实，而不是仅靠定性判断。

**四个核心指标**：

#### 指标 1：毛利率（Gross Margin）
- **高毛利 (>50%)**：通常有定价权（品牌/专利/切换成本）
- **中毛利 (30-50%)**：有一定竞争优势但不突出
- **低毛利 (<30%)**：商品化竞争，护城河可疑

#### 指标 2：ROIC（投入资本回报率）
**公式**：NOPAT ÷ (总资产 - 无息流动负债)

**注意会计陷阱**：
- 公司有大量收购历史 → 商誉会膨胀分母 → ROIC 被低估
- 需同时看"含商誉 ROIC"和"剔除商誉 ROIC"，差距 >5pp 时必须说明

| ROIC 水平 | 含义 |
|----------|------|
| > 20% | 强护城河，且持续创造超额回报 |
| 15-20% | 不错，接近理想 |
| 10-15% | 一般，高于资本成本但不突出 |
| < 10% | 警惕，可能正在摧毁价值 |

#### 指标 3：收入稳定性（Revenue Stability）
- 过去 5 年收入增速标准差 < 5%？→ 防御性强
- 有没有单一年份暴跌 > 10%？→ 周期性风险
- 新冠 2020 年收入下滑幅度？→ 真实的防御性测试

#### 指标 4：自由现金流转化率（FCF Conversion）
**公式**：FCF ÷ 净利润 × 100%

- **> 90%**：盈利质量极高，会计利润真实反映现金
- **70-90%**：正常
- **< 70%**：警惕，可能有激进会计或资本密集型扩张

**一次性项目剥离**：
- 税务和解、资产减值、重组费用 → 从 FCF 中识别并说明
- 调整后 FCF = 报告 FCF + 确认的一次性支出

---

### Step 4：估值（Valuation）

**目标**：在合理假设下，这只股票今天的价格是便宜、合理还是昂贵？

#### 方法 1：P/E 相对估值

```
当前 P/E = 当前价格 ÷ TTM EPS
合理 P/E 范围 = 历史均值 ± 1 标准差（通常 10 年历史）
```

判断：
- 当前 P/E < 历史均值 → 相对低估（但要问：为什么便宜？有没有结构性变差）
- 当前 P/E > 历史均值 × 1.2 → 相对高估（但要问：增速加速了吗？）

#### 方法 2：FCF 收益率 vs 无风险利率

```
FCF Yield = 正常化 FCF ÷ 市值
当前无风险利率 = 10 年期美债收益率（约 4.5%）
```

判断框架：
- FCF Yield > 无风险利率 × 1.5 → 安全边际充足
- FCF Yield ≈ 无风险利率 → 合理定价，无明显溢价
- FCF Yield < 无风险利率 → 你在为增长预期付溢价，需要增长假设成真

#### 方法 3：简单 DCF 直觉（可选）

不要做精确 DCF，但可以用"反向 DCF"——

**问题**：当前价格隐含了多少增长预期？

```
隐含增长率 ≈ (FCF Yield - 无风险利率) 是否合理？
```

如果当前 FCF Yield 为 3%，无风险利率 4.5%，则市场隐含"未来 FCF 增速足够高弥补这 1.5% 的差距"——这个假设合理吗？

#### 安全边际估算

```
目标买点 ≈ 历史均值 P/E × 正常化 EPS × 0.85（留 15% 安全边际）
```

## 执行流程

1. **识别股票代码**：将中文名/英文简称映射为富途完整代码（参考 futuapi skill 代码表）
2. **新闻快扫**：调用 `futu-stock-digest` 获取近 7 天新闻摘要，识别红旗信号，记录到"近期重要事件"
3. **并行拉取数据**：futuapi 行情 + 5 条 Tavily 财务查询**同时发出**，不要串行等待
4. **检查数据质量**：PE 是否异常（负值/极高）？FCF 是否有明显一次性项目？新闻中是否有影响数据解读的重大事件？
5. **填充四步框架**：按 Step 1→4 顺序分析，每步结论必须有数据支撑；如新闻红旗与静态分析矛盾，需在该步骤明确说明
6. **输出报告**：使用下面的模板，结论要有证伪视角，"近期重要事件"章节不可省略

## 常见会计陷阱速查

| 陷阱 | 场景 | 处理方法 |
|------|------|---------|
| 商誉膨胀 ROIC | 并购历史丰富的公司（KO、MSFT、MA）| 同时报告含/不含商誉两个口径 |
| FCF 一次性波动 | 税务和解、资产出售、重组 | 识别并调整，用 3 年均值正常化 |
| PE 失真 | 亏损股、周期底部、大额减值 | 改用 EV/EBITDA 或 P/FCF |
| 高分红侵蚀内生价值 | 分红率 > FCF | 问"分红是否可持续" |
| 收入增长靠并购 | 有机增长 vs 收购增长 | 查 organic revenue growth |
