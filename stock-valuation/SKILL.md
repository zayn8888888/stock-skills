# 股票三维估值计算

## 使命

把股票估值的"黑盒"变成"玻璃盒"——每一个数字从哪里来、为什么这么算、假设是否合理，全部透明呈现。

## 前置依赖

本 skill **依赖能调用富途 OpenAPI 的 skill / 脚本集**（例如社区 `futuapi` skill），自身不包含富途脚本。OpenD 未运行时提示用户先启动。下文脚本命令中的路径为与 `futuapi` 约定的**示例**：可替换为你本地的 `skills/futuapi/scripts/...` 或 `~/.claude/skills/futuapi/scripts/...`。

若你使用其他数据源，只要能拿到「现价」「当前市盈率」等价字段即可替换 1a 步骤的命令。

## 执行流程

### Step 0：代码标准化

将用户输入映射为富途代码格式：
- 美股：`US.AAPL`、`US.TSLA`、`US.NVDA`
- 港股：`HK.00700`、`HK.09988`
- A 股：`SH.600519`、`SZ.000001`

### Step 1：并行拉取数据

**同时**执行以下操作（不要串行等待）：

#### 1a. 富途行情数据（当前价格 + 当前 PE）
```bash
python3 skills/futuapi/scripts/quote/get_snapshot.py <CODE> --json
```

#### 1b. Tavily 财务搜索（4 条并行）

```
查询 1：<公司名> annual free cash flow FCF 2022 2023 2024 site:macrotrends.net OR wsj.com OR stockanalysis.com
查询 2：<公司名> EPS earnings per share TTM 2024 2025 estimate forward annual
查询 3：<公司名> historical PE ratio 5 year average low high range
查询 4：<公司名> revenue growth rate 3 year 5 year CAGR analyst estimate 2025 2026
```

### Step 2：整理数据，补全缺口

把拉到的原始数据整理成估值所需的 6 个核心变量：

| 变量 | 说明 | 数据来源 |
|------|------|---------|
| `current_price` | 当前股价 | 富途行情 |
| `ttm_eps` | 过去12个月每股收益（TTM EPS） | Tavily |
| `eps_growth_rate` | 预期 EPS 增速（用近3年历史均值+分析师预测均值） | Tavily |
| `fcf_ttm` | 过去12个月自由现金流（亿/百万，注明单位） | Tavily |
| `pe_range` | 5年历史 P/E 区间：低/均值/高 | Tavily |
| `shares_outstanding` | 流通股数量 | 富途/Tavily |

**数据质量规则**：
- EPS 为负 → P/E 和 PEG 方法不适用，注明"亏损股，该方法跳过"
- FCF 波动 > 30% → 取 3 年均值，不用单年数字
- 缺少某项数据 → 在报告中明确标注"数据不可得，使用行业均值替代：XXX"

### Step 3：三种方法逐步计算

---

#### 方法一：DCF 现金流折现

**逻辑**：把公司未来能赚到的每一分钱，折算回今天值多少。

**参数选取**（需在报告中列出并说明选择理由）：

| 参数 | 默认值 | 适用场景 |
|------|--------|---------|
| 高速增长期 | 5 年 | 标准假设 |
| 高速增长率 | `eps_growth_rate`（不超过 25%） | 来自数据 |
| 永续增长率 | 3%（美国）/ 2.5%（港股/A 股） | 接近 GDP 长期增速 |
| 折现率 WACC | 科技股 9%，消费/金融 8%，高风险成长 10-11% | 按行业调整 |

**计算步骤**（全部展示）：

```
基准 FCF = <fcf_ttm>（亿）

第 1 年 FCF = 基准 × (1 + g)¹
第 2 年 FCF = 基准 × (1 + g)²
...
第 5 年 FCF = 基准 × (1 + g)⁵

终值 = 第5年FCF × (1 + g_永续) / (WACC - g_永续)

各年现金流现值 = FCFₙ / (1 + WACC)ⁿ
终值现值 = 终值 / (1 + WACC)⁵

企业总价值 = Σ各年现值 + 终值现值

每股内在价值 = 企业总价值 / 流通股数
```

**敏感性分析**（必须展示）：

| WACC \ 增长率 | g-2% | g | g+2% |
|-------------|------|---|------|
| WACC-1% | $XX | $XX | $XX |
| WACC | $XX | **$XX** | $XX |
| WACC+1% | $XX | $XX | $XX |

中心格为基准估值，周边格展示假设变化时的价格范围。

---

#### 方法二：P/E 相对估值

**逻辑**：和自己的历史比——市场在类似情况下愿意为每 $1 利润付多少钱。

**计算步骤**：

```
数据输入：
  TTM EPS = $<ttm_eps>
  历史 PE：低点 = <pe_low>x，均值 = <pe_mid>x，高点 = <pe_high>x

估值区间：
  悲观估值 = TTM EPS × PE 低点 = $<ttm_eps> × <pe_low> = $XX
  中性估值 = TTM EPS × PE 均值 = $<ttm_eps> × <pe_mid> = $XX
  乐观估值 = TTM EPS × PE 高点 = $<ttm_eps> × <pe_high> = $XX

当前 PE = 当前价格 / TTM EPS = $<current_price> / $<ttm_eps> = <current_pe>x

当前 PE vs 历史均值：[高 X% / 低 X%]，处于历史 X% 分位
```

---

#### 方法三：PEG 成长调整估值

**逻辑**：增长更快的公司应该享受更高 P/E，PEG 是增速校正后的真实估值。

```
PEG = 当前 P/E ÷ EPS 增速（%）

合理 PEG 区间：
  保守：1.0（纯价值视角）
  合理：1.0 ~ 1.5（成长股主流范围）
  激进：1.5 ~ 2.0（高增速可接受）

合理 PE 范围 = EPS 增速 × PEG 区间
  保守 PE = <eps_growth>% × 1.0 = <pe_conservative>x
  中性 PE = <eps_growth>% × 1.25 = <pe_neutral>x
  激进 PE = <eps_growth>% × 1.5 = <pe_aggressive>x

PEG 估值区间：
  保守价格 = TTM EPS × 保守 PE = $XX
  中性价格 = TTM EPS × 中性 PE = $XX
  激进价格 = TTM EPS × 激进 PE = $XX

当前 PEG = 当前 PE / EPS 增速 = <current_pe>x / <eps_growth>% = <current_peg>
解读：PEG > 1.5 通常被认为偏贵；PEG < 1.0 通常被认为低估
```

### Step 4：汇总区间 + 买点建议

**加权平均逻辑**：
- 三种方法各有侧重：DCF 看长期内在价值，P/E 看市场情绪锚点，PEG 看增速性价比
- 若三者差距 < 20%，取简单均值；若差距 > 20%，展示分歧原因
- 默认权重：DCF 40%、P/E 35%、PEG 25%（可根据公司特性调整，需说明）

```
综合估值区间：
  低端 = min(DCF低, PE低, PEG低) 的加权值
  中枢 = 三种方法中性价值的加权均值
  高端 = max(DCF高, PE高, PEG高) 的加权值

安全边际买点（打七折）= 中枢 × 0.70
强力买点（打六折）= 中枢 × 0.60

当前价格 $XX 相对中枢：
  [高估 X% / 低估 X% / 处于合理区间]
```

## 常见陷阱与处理规则

| 场景 | 处理方式 |
|------|---------|
| EPS 为负（亏损股）| 跳过 P/E 和 PEG，仅用 DCF；用 P/S 或 EV/Revenue 作补充参考 |
| FCF 单年大幅波动 | 取 3 年均值，标注"已正常化" |
| 成长股 P/E > 50x | 说明历史均值可能不代表当前阶段，侧重 PEG 和 DCF |
| 高增速公司（> 25%）| DCF 增速上限设 25%，超出部分用保守数字并注明 |
| 港股/A 股 | WACC 使用本地无风险利率（港股约 4%，A 股约 3%），永续增长率用 2.5% |
| 数据搜索失败 | 明确告知用户哪项数据缺失，并说明用了什么替代假设 |
