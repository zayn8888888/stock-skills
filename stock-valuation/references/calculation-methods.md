# 三种估值方法完整计算步骤

## 方法一：DCF 现金流折现

**逻辑**：把公司未来能赚到的每一分钱，折算回今天值多少。

**参数选取**（报告中列出并说明选择理由）：

| 参数 | 默认值 | 适用场景 |
|------|--------|---------|
| 高速增长期 | 5 年 | 标准假设 |
| 高速增长率 | `eps_growth_rate`（不超过 25%） | 来自数据 |
| 永续增长率 | 3%（美国）/ 2.5%（港股/A 股） | 接近 GDP 长期增速 |
| 折现率 WACC | 科技股 9%，消费/金融 8%，高风险成长 10-11% | 按行业调整 |

**计算步骤（全部展示）**：

```
基准 FCF = <fcf_ttm>（亿）

第 1 年 FCF = 基准 × (1 + g)¹
第 2 年 FCF = 基准 × (1 + g)²
...
第 5 年 FCF = 基准 × (1 + g)⁵

终值 = 第5年FCF × (1 + g_永续) / (WACC - g_永续)

各年现金流现值 = FCFₙ / (1 + WACC)ⁿ
终值现值 = 终值 / (1 + WACC)⁵

企业总价值 = Σ各年现值 + 终值现值
每股内在价值 = 企业总价值 / 流通股数
```

**敏感性分析（必须展示）**：

| WACC \ 增长率 | g-2% | g | g+2% |
|-------------|------|---|------|
| WACC-1% | $XX | $XX | $XX |
| WACC | $XX | **$XX** | $XX |
| WACC+1% | $XX | $XX | $XX |

## 方法二：P/E 相对估值

**逻辑**：和自己的历史比——市场在类似情况下愿意为每 $1 利润付多少钱。

**计算步骤**：

```
数据输入：
  TTM EPS = $<ttm_eps>
  历史 PE：低点 = <pe_low>x，均值 = <pe_mid>x，高点 = <pe_high>x

估值区间：
  悲观估值 = TTM EPS × PE 低点 = $XX
  中性估值 = TTM EPS × PE 均值 = $XX
  乐观估值 = TTM EPS × PE 高点 = $XX

当前 PE = 当前价格 / TTM EPS = <current_pe>x
当前 PE vs 历史均值：[高 X% / 低 X%]，处于历史 X% 分位
```

**Futu `get_valuation_detail` 直接提供**：
- `trend['current_value']` 当前 PE
- `trend['average_value']` 历史均值
- `trend['avg_minus_1_stddev']` 均值 -1σ（历史低 PE 参考）
- `trend['avg_plus_1_stddev']` 均值 +1σ（历史高 PE 参考）
- `trend['valuation_percentile']` 当前百分位（0~1）

## 方法三：PEG 成长调整估值

**逻辑**：增长更快的公司应该享受更高 P/E，PEG 是增速校正后的真实估值。

```
PEG = 当前 P/E ÷ EPS 增速（%）

合理 PEG 区间：
  保守：1.0（纯价值视角）
  合理：1.0 ~ 1.5（成长股主流范围）
  激进：1.5 ~ 2.0（高增速可接受）

合理 PE 范围 = EPS 增速 × PEG 区间
  保守 PE = <eps_growth>% × 1.0
  中性 PE = <eps_growth>% × 1.25
  激进 PE = <eps_growth>% × 1.5

PEG 估值区间：
  保守价格 = TTM EPS × 保守 PE = $XX
  中性价格 = TTM EPS × 中性 PE = $XX
  激进价格 = TTM EPS × 激进 PE = $XX

当前 PEG = 当前 PE / EPS 增速 = <current_peg>
解读：PEG > 1.5 通常偏贵；PEG < 1.0 通常低估
```

## Step 4：汇总区间 + 买点

**加权逻辑**：
- 三方法侧重不同：DCF 看长期内在价值，P/E 看市场情绪锚，PEG 看增速性价比
- 差距 < 20% 取简单均值；差距 > 20% 展示分歧原因
- 默认权重：DCF 40%、P/E 35%、PEG 25%（按公司特性可调，需说明）

```
综合估值区间：
  低端 = min(DCF低, PE低, PEG低) 的加权值
  中枢 = 三种方法中性价值的加权均值
  高端 = max(DCF高, PE高, PEG高) 的加权值

安全边际买点（7折）= 中枢 × 0.70
强力买点（6折）= 中枢 × 0.60
```

## 常见陷阱与处理

| 场景 | 处理方式 |
|------|---------|
| EPS 为负（亏损股） | 跳过 P/E 和 PEG，仅用 DCF；补 P/S 或 EV/Revenue |
| FCF 单年大幅波动 | 取 3 年均值，标注"已正常化" |
| 成长股 P/E > 50x | 说明历史均值可能不代表当前阶段，侧重 PEG 和 DCF |
| 高增速公司（> 25%） | DCF 增速上限设 25%，超出部分用保守数字并注明 |
| 港股/A 股 | WACC 用本地无风险利率（港股约 4%，A 股约 3%），永续增长率 2.5% |
| 数据搜索失败 | 明确告知哪项数据缺失，说明用了什么替代假设 |
