# 港股 IPO 输出前自检清单

先读本清单再执行。最终输出前再逐项复核。每项只能标 `done`、`failed_after_search`、`legal_na`，不能用"需补 / 未完成 / 后续再查"代替执行结果。

## 意图与阶段

- [ ] 用户问的是市场级 IPO 日历，还是单只 IPO / 新上市股票？
- [ ] 是否明确阶段：递表 / 已通过聆讯 / 招股中 / 已定价待上市 / 上市首日 / 上市后 N 天？
- [ ] 未上市公司是否避免编造股票代码？
- [ ] 模板选择是否匹配用户意图（Template 1/2/3/4/A）？

## 数据来源

- [ ] 是否调用 `get_ipo_list.py HK --json`（市场级或需要发行列表时）？
- [ ] 已上市标的是否调用 `get_snapshot.py`、`get_stock_info.py`、`get_company_profile.py`？
- [ ] 是否在近期 / 最新 / 本周 IPO 问题中使用 Tavily / WebSearch 查实时来源？
- [ ] 单只 IPO 是否至少尝试一次官方源搜索（HKEXnews / 公司 IR）？
- [ ] 港股 IPO 是否按 `hkex-documents.md` 从 New Listing Information / AP & PHIP / Title Search 解析 PDF href，而不是手拼 PDF URL？
- [ ] 港股招股书 / PHIP / 配发结果是否记录 PDF URL、source page URL、抓取时间，下载后是否记录 sha256（可得时）？
- [ ] Futu 字段缺发行价、上市日、募资额、锁定期时，是否用搜索补证后再标缺口？
- [ ] 每个数字是否标来源？

## 执行门控

- [ ] G1 官方文件：至少一次官方源搜索；港股是否查 HKEXnews PDF href？
- [ ] G2 发行结构：发行价、上市/申购日期、募资用途、承销商/保荐人、锁定期/解禁窗口？
- [ ] G3 保荐人战绩：近 12/24 个月样本、破发率、上涨率、中位收益？或合法 N/A？
- [ ] G4 同业估值：3-5 家同业估值锚？或列出搜索词和不足原因？
- [ ] G5 上市后交易质量：发行价 vs 当前价、首日收盘、破发状态、成交/换手？或合法 N/A？
- [ ] G6 checklist 自检：在综合结论前完成本 checklist，而不是报告写完后补看？
- [ ] G7 双评分：IPO Trade Score 和 Fundamental Holding Score 都已计算？置信度已标注？Preliminary/Final 已标明？可能改变评分的缺失数据已列出？

## 评分自检

- [ ] IPO Trade Score：7 个因子全部评估？权重之和 = 100%？
- [ ] Fundamental Holding Score：6 个因子全部评估？权重之和 = 100%？
- [ ] 置信度是否基于文件可用性正确分配（Prospectus 可用 = High；仅 AP = Low）？
- [ ] 评分解读标签是否匹配范围表（80-100 = Strong 等）？
- [ ] 评分是否未被转换为直接申购/买入/卖出指令？
- [ ] 正面驱动因素和负面驱动因素是否都已列出？
- [ ] 缺失数据是否已列出（可能改变评分）？

## 模板选择自检

- [ ] 模板是否匹配用户意图？
  - 简短问题 → Template 1（一页式摘要）
  - 暗盘/首日预测 → Template 2（暗盘情景）
  - 卖出策略 → Template 3（退出框架）
  - 深度分析 → Template 4（深度报告 16 节）
  - 市场级日历 → Template A
- [ ] 简短问题是否没有生成不必要的长报告？
- [ ] 深度分析请求是否没有只输出一页式摘要？

## 港股 IPO 核心字段

- [ ] 发行价 / 定价区间是否确认？
- [ ] 上市日 / 申购期是否确认？
- [ ] 募资额 / 募资用途是否确认？
- [ ] 承销商 / 保荐人是否确认？
- [ ] 保荐人战绩是否列出样本数、首日破发率、当前破发率、当前上涨率、首日/当前收益中位数？
- [ ] 保荐人样本不足、行业集中或缺发行价/价格数据时，是否标注样本偏差并剔除缺失样本？
- [ ] 流通盘、基石/战略配售、锁定期/解禁窗口是否确认或明确缺失？
- [ ] 基石投资者名单和锁仓期是否列出？
- [ ] 绿鞋 / 稳价人是否确认？
- [ ] 老股出售是否确认？
- [ ] 回拨机制和最终回拨结果是否确认？
- [ ] 招股书主要风险是否列出 1-3 条？

## 市场需求（如适用）

- [ ] 公开发售超额认购倍数是否确认？
- [ ] 孖展倍数是否确认？
- [ ] 国际配售覆盖倍数是否确认？
- [ ] 配售比例和一人一手中签率是否确认？
- [ ] 缺失的需求数据是否标注为缺口，而非凭印象估算？

## 判断纪律

- [ ] 是否避免输出"建议申购 / 建议买入 / 必破发 / 必涨"？
- [ ] 亏损或 pre-revenue 公司是否没有硬套 PE？
- [ ] 上市不满 90 个交易日时，是否标注技术面/估值分位数据不足？
- [ ] 缺字段是否写"未确认"，没有用估算替代事实？
- [ ] 报告中是否没有裸写"需补 / 未完成 / 后续可查"；所有缺口是否都有已执行的搜索词、调用或合法跳过原因？
- [ ] 暗盘是否使用情景分析（熊/基/牛三档），而非单点价格预测？
- [ ] 卖出策略是否使用情景化退出框架，而非直接指令？
- [ ] 结论是否使用谨慎标签（见 scoring-framework.md 第 5 节）？

## 跨 skill

- [ ] 用户要交易层面的"能不能买 / 是否加仓"时，是否建议调用 `stock-analyzer` 补九维度？
- [ ] 用户要市场热点时，是否转 `market-scanner`？
