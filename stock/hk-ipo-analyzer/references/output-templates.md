```markdown
**<公司名 / 代码> · <查询字段>**

- 数据时间：YYYY-MM-DD HH:mm HKT

<如适用：PDF URL / 来源页面 URL / 文件类型>
```

当用户询问配售后的操作、止盈止损或退出策略时使用。不得写"立即卖出"、"继续持有"等直接指令。

### 情景化退出 / 风险管理框架

**Board lot:** xxx shares

- 板块情绪走弱
- 同类标的估值下修
- 锁仓解禁压力临近
- 稳价期结束后流动性枯竭
