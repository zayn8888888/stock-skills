# 港股 IPO 研究方法论

## 1. 研究目标

产出结构化、有据可查的投行风格研究材料。不是选股机器人、交易信号工具或个性化投资顾问。

## 2. 信源层级

按以下优先级使用信源：

1. **HKEXnews / 披露易官方文件**（最高优先）
   - New Listing Information
   - AP & PHIP
   - Title Search
   - Prospectus / 招股书
   - Application Proof / 申请版本
   - PHIP / 聆讯后资料集
   - Allotment Results / 配发结果
   - Listing Announcement / 上市公告

2. **公司官方来源**
   - 公司官网
   - 投资者关系页面
   - 官方新闻稿

3. **交易所与监管来源**
   - HKEX 公告
   - 上市规则引用
   - 监管公告

4. **补充来源**
   - 券商平台
   - 财经数据库
   - 主流财经媒体

5. **排除或弱信源**
   - 未经核实的社交媒体
   - 论坛
   - 传闻
   - 无来源截图
   - 无出处数据表

> 暗盘 / grey market 数据仅为补充情绪指标。

## 3. 阶段研究逻辑

### 3.1 递表 / Application filed

主要文件：Application Proof

重点：
- 商业模式
- 收入结构
- 盈利能力
- 风险因素
- 保荐人身份
- 募资用途（如已披露）
- 上市理由

不应期望：Prospectus、Allotment Results、Listing Announcement、最终发行价

### 3.2 已通过聆讯 / Passed hearing

主要文件：PHIP

重点：
- 更新的财务数据
- 业务和风险披露
- 发售前结构
- 潜在发售方向
- 保荐人和承销团（如可得）

不应期望：最终发行价、Allotment Results、Listing Announcement

### 3.3 招股中 / Public offering ongoing

主要文件：Prospectus

重点：
- 发行价区间
- 每手股数与入场费
- 公开发售部分
- 国际配售部分
- 回拨机制（Clawback Mechanism）
- 基石投资者（Cornerstone Investors）
- 超额配售选择权（Over-allotment Option）
- 稳价人（Stabilizing Manager）
- 募资用途
- 财务报表
- 风险因素
- 估值锚

### 3.4 已定价待上市 / Priced and awaiting listing

主要文件：Prospectus + Allotment Results

重点：
- 最终发行价
- 公开发售超额认购倍数
- 国际配售覆盖倍数
- 最终回拨
- 配售比例（allocation rate）
- 一人一手中签率
- 自由流通市值
- 基石参与情况
- 隐含市值
- 上市前供需压力

### 3.5 上市首日 / First trading day

主要来源：Prospectus + Allotment Results + Listing Announcement + 交易数据

重点：
- 当前价 vs 发行价
- 开盘价
- 盘中最高 / 最低
- 首日收盘
- 成交额
- 换手率
- 是否跌破发行价
- 价格行为是否有流动性支撑
- 是否出现高开低走模式

### 3.6 上市后 180 天内 / Listed within 180 days

重点：
- 当前价 vs 发行价
- 当前价 vs 首日收盘价
- 上市后最高 / 最低
- 回撤幅度
- 成交趋势
- 流动性衰减
- 稳价期
- 基石锁仓
- 控股股东锁仓
- Pre-IPO 投资者锁仓
- 员工期权
- 老股出售
- 30 / 90 / 180 天供给压力

> 不要假设所有锁仓都在第 180 天到期。核实具体条款。

## 4. 核心研究维度

### 4.1 发行结构

检查项：
- 发行价 / 价格区间
- 最终发行价
- 发行股数
- 募资总额
- 每手股数
- 入场费
- 市值
- 自由流通市值
- 公开发售比例
- 国际配售比例
- 回拨机制
- 基石投资者
- 基石锁仓期
- 超额配售选择权
- 稳价人
- 老股出售
- Joint Sponsors
- Overall Coordinators
- Global Coordinators
- Bookrunners

解读：
- 小流通盘 + 强需求 = 短期交易弹性更高
- 大流通盘 + 弱需求 = 供给压力更大
- 高基石占比可减少自由流通但也可能限制流动性
- 老股出售增加供给压力并削弱增长叙事

### 4.2 市场需求

检查项：
- 公开发售超额认购倍数
- 孖展倍数
- 认购人数
- 国际配售覆盖倍数
- 回拨结果
- 配售比例
- 一人一手中签率

解读：
- 500x+ 公开认购与约 2x 认购应有实质不同的评分
- 缺失需求数据必须标注为数据缺口
- 不凭印象估算需求

### 4.3 业务质量

检查项：
- 主营业务
- 收入结构
- 毛利率
- 净利润 / 净亏损
- 调整后净利润
- 经营现金流
- 自由现金流（如适用）
- 客户集中度
- 供应商集中度
- 研发支出
- 销售及营销支出
- 关联交易
- 关键风险因素
- 募资用途

解读：
- 收入高增长但无经营杠杆未必支撑长期估值
- 高客户集中度增加盈利波动性
- 负经营现金流需要现金跑道分析
- 募资用途应对应真实增长瓶颈

### 4.4 估值锚

A/H 比较（适用时）：
- A 股最新价格
- H 股发行价
- 汇率
- A/H 折价或溢价
- 市值
- P/E、P/S、EV/Sales、EV/EBITDA（适用时）

无 A 股锚时：
- 选取 3–5 家可比公司
- 优先同市场、业务相似、收入结构可比、利润率相近、增长阶段类似
- 不强行匹配弱可比

### 4.5 保荐人与承销团

默认输出：仅初始判断

深度报告：调查 Joint Sponsors、Overall Coordinators、Global Coordinators、Bookrunners 过去 12–24 个月的表现，区分角色权重。若有效样本 < 5，标注样本不足。

## 5. 研究纪律

- 先识别项目阶段
- 优先使用官方文件
- 添加数据时间戳
- 分离短期打新交易机会与基本面持仓质量
- 显式标注缺失数据
- 避免确定性语言
- 避免直接申购/买入/卖出指令
- 关键数字用表格并附来源列
