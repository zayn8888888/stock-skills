# IPO 评分框架

仅在报告级单只 IPO、暗盘情景、退出框架或用户明确要求评分时读取本文件。事实查询和市场级 IPO 日历默认不评分。

## 1. 输出契约

每个评分必须包含：

- 评分名称
- 满分 100 的最终分；合法无法计算时写 `N/A`
- Confidence Level：High / Medium / Low
- Status：Preliminary / Final
- 因子表：0-10 原始分、权重、加权贡献、证据状态、来源
- 正面驱动因素、负面驱动因素、可能改变评分的缺失数据

证据状态只使用以下四类：

| 状态 | 含义 | 评分处理 |
|------|------|----------|
| `actual` | 找到官方或结构化直接数据 | 使用观察到的因子分 |
| `proxy` | 使用有来源的间接证据 | 使用因子分；该因子置信度最高 Medium |
| `failed_after_search` | 已搜索但未找到，或数据尚未发布 | 使用 fallback 分，并降低置信度 |
| `legal_na` | 该因子对该发行或上市类型不适用 | 剔除该因子，按原权重比例分配给其余适用因子 |

不得把 `failed_after_search` 隐藏成高置信评分。分数仍可计算，但必须标 Preliminary 或 Low/Medium confidence。

## 2. 计算规则

每个适用因子打 0-10 分。

```text
加权贡献 = 原始因子分 / 10 * 因子权重
最终分 = round(加权贡献之和)
```

`legal_na` 因子剔除后，把它的权重按其余适用因子的原权重比例重分配。`failed_after_search` 不重分配，使用 fallback 分，让不确定性保留在分数里。

展示计算过程时，加权贡献最多保留 1 位小数。最终分四舍五入到整数。

## 3. 置信度与状态

### Confidence Level

| 等级 | 使用条件 |
|------|----------|
| High | 已获得 Prospectus 和相关官方文件；发行结构、估值输入、阶段对应的需求或交易数据已确认 |
| Medium | 已获得 Prospectus 或 PHIP；需求、配售、同业估值或保荐人数据部分缺失；使用了 proxy |
| Low | 只有 Application Proof 或媒体摘要；没有最终发行价或配售数据；估值锚或保荐人数据较弱 |

### Status

| 状态 | 使用条件 |
|------|----------|
| Preliminary | 尚未上市、Allotment Results 未发布、最终发行价未确定，或关键因子数据尚未发布 |
| Final | 最终发行价、Prospectus、Allotment Results 和阶段对应交易数据均可得 |

## 4. IPO Trade Score / 打新评分

用于短期 IPO setup、暗盘情景和首日供需框架。它不是申购指令。

### 权重

| 因子 | Pre-allotment 权重 | Post-allotment / 首日权重 |
|------|--------------------|---------------------------|
| 市场需求与认购热度 | 10 | 20 |
| 流通盘、配售与供需结构 | 30 | 25 |
| 板块主题与短期情绪 | 10 | 10 |
| A/H 或同业估值锚 | 20 | 15 |
| 定价弹性 | 10 | 10 |
| 保荐人 / 承销团短期战绩 | 10 | 10 |
| 基本面风险过滤 | 10 | 10 |

Pre-allotment 指仍在招股、或 Allotment Results 尚未发布。此阶段使用 pre-allotment 权重，不再把需求权重重分配。除非有已核验的孖展或认购 proxy，否则需求因子给 5 分，并标 `failed_after_search` 或"尚未发布"。

### 因子分档

#### 市场需求与认购热度

| 原始分 | 锚点 |
|--------|------|
| 9-10 | 公开发售认购 500x+ 或确认的极强需求，认购基础广泛，国际配售强，回拨有意义 |
| 7-8 | 公开发售认购 50-500x，或孖展/配售需求确认强劲 |
| 5-6 | 中等需求，约 5-50x 公开认购，或需求信号分化 |
| 3-4 | 低于 5x、孖展疲弱，或配售结果显示参与度弱 |
| 0-2 | 认购不足或发行显著失败 |
| fallback | 需求数据尚未发布时给 5，并标 `failed_after_search` 或 `proxy` |

#### 流通盘、配售与供需结构

| 原始分 | 锚点 |
|--------|------|
| 9-10 | 有效自由流通盘小、供应紧、锁仓可信、基石锁仓有意义、有绿鞋/稳价、无明显老股出售压力 |
| 7-8 | 流通和供给结构整体可控 |
| 5-6 | 中性结构；有一定供给压力但不主导 |
| 3-4 | 流通盘大、回拨后公开供应高、锁仓弱、老股出售或稳价安排不清 |
| 0-2 | 供给压力极大，或结构主要由套现/卖压主导 |
| fallback | 官方搜索后仍无法确认流通结构时给 5 |

#### 板块主题与短期情绪

| 原始分 | 锚点 |
|--------|------|
| 9-10 | 同行业港股 IPO 和市场风险偏好在数据时点均显著正面 |
| 7-8 | 板块和 IPO tape 支持 |
| 5-6 | 板块情绪中性或分化 |
| 3-4 | 板块弱，或近期同类 IPO 表现差 |
| 0-2 | 大盘风险偏好极弱，同类标的显著承压 |
| fallback | 当前情绪无法验证时给 5 |

#### A/H 或同业估值锚

| 原始分 | 锚点 |
|--------|------|
| 9-10 | 相对可信 A 股或同业锚明显折价，且增长和利润率可比 |
| 7-8 | 估值有支撑，折价或合理性较清晰，但有小幅可比性限制 |
| 5-6 | 估值大致合理，但安全垫不明显 |
| 3-4 | 相对 A/H 或同业偏贵，可比性弱 |
| 0-2 | 无可信估值支撑，或明显溢价于质量更好的同业 |
| fallback | 已搜索但无可靠同业锚时给 5，并列搜索词 |

#### 定价弹性

| 原始分 | 锚点 |
|--------|------|
| 9-10 | 最终定价留下明显估值空间，且没有落在激进区间位置 |
| 7-8 | 定价合理，不明显拉满 |
| 5-6 | 中性定价，区间位置或估值安全垫分化 |
| 3-4 | 区间上沿或估值偏激进，首日空间有限 |
| 0-2 | 定价重设、需求弱定价，或无支撑的极端溢价 |
| fallback | 最终价/价格区间不可得时给 5，并标 Preliminary |

#### 保荐人 / 承销团短期战绩

| 原始分 | 锚点 |
|--------|------|
| 9-10 | 有效样本 >= 5，破发率低，中位收益为正，且角色匹配 |
| 7-8 | 样本较扎实，首日或当前表现整体正面 |
| 5-6 | 样本分化，或只有头部承销团阵容但缺项目级证据 |
| 3-4 | 样本弱、破发率高，或小型保荐人历史较差 |
| 0-2 | 有效样本显示持续高破发和负中位收益 |
| fallback | 无可靠样本时给 5，整体置信度最高 Low |

样本表可用时，优先用 `scripts/sponsor_performance.py` 计算统计项。

#### 基本面风险过滤

| 原始分 | 锚点 |
|--------|------|
| 9-10 | 盈利或盈利路径可信，现金流干净，集中度低，监管/治理风险有限 |
| 7-8 | 业务质量较好，风险可控 |
| 5-6 | 基本面分化，风险可见但非压倒性 |
| 3-4 | 亏损、高 burn、高集中度或重大风险因素 |
| 0-2 | 持续经营、治理、监管或披露风险严重 |
| fallback | 只有最小业务信息时给 5 |

`-B` 生物科技标的，该因子最高 3 分，除非能引用异常强的临床/商业化证据。此规则只限制风险过滤因子，不摧毁整个 Trade Score。

## 5. Fundamental Holding Score / 持有评分

用于评估 3-24 个月基本面持仓质量。它不是买入指令。

### 权重

| 因子 | 权重 |
|------|------|
| 盈利质量与盈利路径 | 25 |
| 估值合理性 | 25 |
| 行业护城河与增长前景 | 20 |
| 现金流与资产负债表韧性 | 15 |
| 收入质量与客户/供应商集中度 | 10 |
| 治理、关联交易与风险因素 | 5 |

### 因子分档

所有 Fundamental Holding 因子先使用以下通用锚点，再解释公司证据：

| 原始分 | 锚点 |
|--------|------|
| 9-10 | 有强来源证据支持，且重大 caveat 很少 |
| 7-8 | 高于平均，风险存在但可控 |
| 5-6 | IPO 阶段常见的分化或中性证据 |
| 3-4 | 证据弱、重大不确定，或趋势不利 |
| 0-2 | 核心因子严重薄弱或缺乏支持 |
| fallback | 已搜索但无法确认时给 5，并降低置信度 |

附加规则：

- 亏损或 pre-revenue 公司不得用 P/E。
- 按业务使用 P/S、EV/Sales、现金跑道、管线里程碑、AUM/NAV、GMV、ARR 等更合适的锚。
- 上市少于 90 个交易日时，说明技术面历史和估值分位证据尚不成熟。

## 6. 评分解释

### IPO Trade Score

| 分数 | 标签 | 解读 |
|------|------|------|
| 85-100 | Elite | 极少见的强证据组合；仍然只作情景判断 |
| 70-84 | Strong | 短期 IPO setup 较强 |
| 50-69 | Neutral | 短期 setup 分化或中性 |
| 35-49 | Weak | setup 偏弱，或供需结构有明确压力 |
| 0-34 | Very Weak | 供给、需求、估值或风险因素严重不利 |

不得把分数区间映射成确定首日收益。如果使用任何回测校准，必须在报告中引用数据集、样本日期、方法和计算脚本。

### Fundamental Holding Score

| 分数 | 标签 | 解读 |
|------|------|------|
| 80-100 | Strong | 长期基本面证据强 |
| 60-79 | Constructive | 整体支持，但有重要 caveat |
| 40-59 | Mixed | 正负因素均衡 |
| 20-39 | Weak | 基本面问题较明显 |
| 0-19 | Very Weak | 基本面严重薄弱或缺乏支持 |

## 7. 结构性调整

### 共线性检查

当因子高度相关时，在最终取整前折扣边际信息较弱的因子：

- 需求热度 >= 8 且板块情绪 >= 8：板块情绪贡献乘以 0.7。
- 定价弹性 >= 8 且流通盘结构 >= 8：定价弹性贡献乘以 0.7。

折扣后不重新归一化。折扣本身就是重复证据的惩罚。

### 特殊上市类型

| 结构 | 处理 |
|------|------|
| 无发行价的介绍上市 | IPO Trade Score 为 `N/A`；仍可计算 Fundamental Holding Score |
| `-B` 生物科技 | 基本面风险过滤因子最高 3 分，除非引用异常强证据 |
| `-W` 同股不同权 | 在流通/治理因子讨论控制权风险；没有披露投票权数据时不得机械调整流通盘 |

## 8. 允许与禁止措辞

允许：

- "IPO trade setup appears strong, subject to final allocation and market sentiment."
- "The score is Preliminary because subscription and allocation data are not yet available."
- "持有评分中性，盈利路径尚不明确。"

禁止：

- "建议申购"
- "必须买"
- "一定卖"
- "稳赚"
- "无风险"
- "必涨"
- "必破发"
