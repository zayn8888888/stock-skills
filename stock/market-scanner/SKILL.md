# 市场热点扫描

## 核心原则

1. **发现与验证双通道**：热点来源分两路——① 富途 API（涨幅 / 资金）② Tavily 新闻/社交。**两路都要主动发现**，不能只让新闻做"已上榜板块的验证"，否则会漏掉还在媒体铺垫阶段的跨行业主题（AI 产业链 / HBM / 存储 / 核聚变等）
2. **扫描为主，受约束外推为辅**：先用数据扫"现在哪些板块热"（L1-L4），再基于产业链传导逻辑外推"热点会传到哪"（L5）。外推**必须落到具体板块/股票 + 必须列反驳点 + 必须用 L1 信号回测**，不允许写"我看好 XX 方向"这类空泛叙事
3. **多重信号交集**：板块上榜至少需要 A 涨幅 / B 资金 / C 新闻 三者中命中 ≥ 2，单一维度上榜的扔进候补池
4. **指数可骗人，必用成分股中位数复核**：任何板块涨幅/资金信号都必须用"成分股 5 日涨幅中位数"再校验一次，背离超 5pp 直接标"权重法伪信号"
5. **集中度是前置门槛不是事后标注**：若板块前 1-2 只成交占比 >50%，板块信号 ≈ 这几只的信号，下游候选阶段必须强制降级
6. **候选不是推荐**：板块内 3-5 只候选只是"符合筛选条件的标的"，最终判断必须经 stock-analyzer 八维度复核
7. **拒绝尾端追涨**：同一只票若近 5 日累计涨幅已超板块 + 8pp，自动降权（已过度拉升）
8. **质量阀门优先于性价比**：市值 / 流动性 / 亏损状态的硬阀门先过，PE 分位排序在后

## 前置依赖

- **东方财富 HTTP API（A 股主数据源）**：免费公开接口，无需认证。A 股板块扫描首选，覆盖 486 个概念板块（远超富途 INDUSTRY 的 131 个），f109 字段（5日涨幅）经实测与富途误差 < 0.01%。完整代码、字段说明、BK 代码表、NOISE_KEYWORDS 过滤列表见 [references/api-eastmoney.md](references/api-eastmoney.md)。

- **富途 API（个股深度数据源）**：依赖 OpenD 运行，`pip install futu-api`。负责个股 PE / 市值 / K线 / 资金流深度数据，以及港美股板块 K 线扫描。**A 股大量概念板块 `get_plate_stock` 返回"未知股票"，升级 OpenD 无效，A 股板块扫描一律走东财。** 方法对照表、港美股板块 K 线代码、资金流 DAY fallback 规则见 [references/api-futu.md](references/api-futu.md)。

- **Tavily**：`mcp__plugin_tavily-web-search_tavily-web-search__tavily_search`。强依赖，主题发现（L0）必须靠它，不能降级跳过。

- **event-calendar skill**（可选但强烈推荐）：用于 L2「催化（前瞻）」与 L5 外推的可证伪催化日历。未安装时回退为"仅回看催化"，报告局限里说明。

- **hyperliquid-perps skill**（可选，**仅美股维度**）：用于 L2 链上拥挤度与 L3 funding 因子评分。**港股板块不适用**（链上港股镜像 OI < 10 万 USD，信号无效）；**A 股不适用**（无链上镜像）。未安装时跳过链上维度。

## 扫描范围

港股（HK）+ 美股（US）+ A股（CN）。用户可显式指定单一市场，默认并行扫三个市场并分开出报告。新加坡 / 日本暂不支持。

**A 股特殊说明**：板块扫描走东财 API；富途代码格式 `SH.600519` / `SZ.000858`；无 Hyperliquid 链上镜像，链上拥挤度维度全部跳过，改用「北向资金净流入 + 超大单资金流」替代。

## 时间窗口

| 窗口 | 数据来源 | 用途 |
|------|---------|------|
| **5 日涨幅** | 东财 f109 / 富途 K 线 | 当前热度，第一层筛选 Top 20 |
| **多周时序（近 4 周）** | 东财历史 K 线 / 富途板块 K 线 | 性质判断：持续主线 vs 脉冲热点 |
| **资金流历史（近 36 天）** | 富途 `get_capital_flow(DAY)` | 机构是否连续 3 周+ 净流入 |

**严禁**用"今日涨幅"作为板块筛选口径；今日回调但多周累计强势的板块同样必须进候选池。A 股涨跌停机制导致日度数据失真，日度噪音 > 信号。

## 大盘状态门控（强制前置，所有市场）

**在进入 L0 之前先判断大盘状态**，决定本次扫描的执行力度：

| 状态 | 判断标准 | 对扫描的影响 |
|------|---------|------------|
| 🟢 上升通道 | 主要指数站上 20 日均线 + 近 5 日未破 | 正常执行全流程 |
| 🟡 震荡整理 | 指数在 20 日均线附近 ±3% 反复 | L1.5 准入门槛加严：要求连涨 ≥ 4 周才标「持续主线」；L3 评分阈值 +1 |
| 🔴 下跌通道 | 连续 3 日收于 20 日均线下方 + 近 5 日跌幅 > 5% | 报告开头标注「系统性杀跌，热点信号可信度低」；L5 外推跳过；仅输出防御方向候补池 |

> 各市场独立判断：A 股看上证指数，港股看恒生指数，美股看 SPX/NDX。三市可以同时处于不同状态。

## 扫描流程（6 层漏斗）

```
大盘门控（强制前置，🔴 时降级输出）
     ↓
L0 主题发现（Tavily 广撒网挖热词 + 反向映射板块 + 催化来源可信度标签）
     ↓
L1 板块热度三重信号（INDUSTRY ∪ CONCEPT 并扫）→ 每市场 Top 5 板块候选
     ↓
L1.5 轮动时序（4 周历史K线，性质判断：持续主线 / 次级主线 / 脉冲热点 / 退潮）
     ↓
L2 热度质量验证（权重法背离检查 + 集中度前置门槛 + 持续性/广度/催化/链上拥挤度标注）
     ↓
L3 板块内候选性价比向量（硬阀门 + 软打分）→ 每板块 3-5 候选
     ↓
L4 收敛 → 总 3-5 个最终候选 + 衔接 stock-analyzer
     ↓
L5 产业链外推（基于 L1-L4 主热点做传导推断 + 数据回测）→ 标注"已在动 / 没在动"
```

### L0 主题发现（Tavily 自由热词扫描）

目标：先在新闻/社交里主动挖主题，而不是等 API 榜单告诉我们哪个板块热。

每市场各一组 Tavily query 并行打（HK 中英混合，US 纯英文，CN 纯中文）：

```
HK 组：港股领涨板块主线 / ETF资金流入 / sector rotation / 雪球热门板块
US 组：US sector leaders / AI chip HBM rally / SPDR ETF inflow / WSB trending
CN 组：A股涨停板块题材 / 北向资金加仓概念 / 东方财富人气概念 / 政策利好行业
```

产出「主题候选清单」，每条主题带 1-3 个代表性板块代码或关键词，反向映射靠 `get_plate_list` 的 CONCEPT 清单做关键词匹配，不要靠 LLM 凭记忆编代码。

**对每条识别出的主题，打催化来源可信度标签**（决定 L1.5 轮动时序的性质上限和 L5 外推的置信度）：

| 可信度 | A 股 | 港股 | 美股 |
|--------|------|------|------|
| ⭐⭐⭐ 一级 | 政策文件/国家规划/国务院专项 | 中国政策落地 + 南向资金连续 3 日净流入 | 财报超预期/产品首次商用/FDA 批准 + 美联储政策明确转向 |
| ⭐⭐ 二级 | 产业技术拐点（首次量产/首个商业合同）、≥3 家券商同题研报 | 全球宏观共振（美联储/美债）、AH 溢价收敛逻辑 | 产业政策落地（IRA/CHIPS Act）、≥3 家机构同向 initiation/upgrade |
| ⭐ 三级 | 财经媒体专题报道 | 机构研报、港股财经媒体 | 主流财经媒体（WSJ/Bloomberg/FT）专题 |
| ⚠️ 警惕 | 社交媒体热传/股吧讨论量飙升（无实质事件支撑） | 雪球/社交热传 | WSB/Twitter 热传（**例外**：小市值 + 高空仓标的，散户舆情可升为二级） |

**来源标签如何影响后续流程**：
- ⭐⭐⭐ 一级来源 → L1.5 轮动时序可接受"次级主线↗"即追（不强求持续主线）；L5 外推允许更多跳传导
- ⭐⭐ 二级来源 → 正常执行，需连涨 ≥ 3 周才进入候选
- ⭐ 三级来源 → L1.5 要求持续主线（4 周全正）才进候选，脉冲热点概率高
- ⚠️ 警惕来源 → 强制标注「纯情绪叙事，慎追」，L5 外推跳过该主题的传导推断

### L1 板块热度三重信号

**信号 A（涨幅榜）**：A 股走东财 `em_get_all_boards()` 取 5 日涨幅 Top 20；港美股用富途 `request_history_kline` 对全量板块计算 5d/10d 涨幅取 Top 20。

**信号 B（资金净流入）**：对候选板块拉成分股资金流，聚合为板块级资金净流入榜 Top 20。美股蓝筹 `get_capital_flow` 返回 0 时启用"成交额 × 涨跌幅"代理，标注「资金代理信号」。

**信号 C（新闻/社交热度）**：对每个候选板块打 3 条并行 Tavily query，统计近 7 日相关新闻条数与正面主题词命中（负面词如"crash / 风险 / 杀跌"命中要反向扣分）。

**信号交集**：板块在 A/B/C 中命中 ≥ 2（L0 主题通道下来的板块命中 ≥ 1）才进 L1.5。

### L1.5 轮动时序

用 4 周历史 K 线判断板块性质，**脉冲热点直接跳过 L2/L3**，仅在报告里标注。详细代码与港美股差异见 [references/rotation-analysis.md](references/rotation-analysis.md)。

> **⚠️ 调用时机**：`em_get_board_kline` 只对通过 L1 多重信号交集（A+B+C ≥2）的板块调用，不对涨幅 Top 20 全量调用。交集结果通常 5-8 个，push2his 配额完全够用；若对 20 个全量调，交易时段必然触发 IP 级限流。

| 性质 | 追板策略 |
|------|---------|
| ✅ 持续主线（4 周全正） | 优先追 |
| 📊 次级主线↗（3 周正且加速） | 可追 |
| 📊 次级主线↘（3 周正但减速） | 谨慎 |
| ⚡ 脉冲热点（前几周负，突然拉升） | 不追 |
| ❄️ 退潮中 | 不追 |

**叠加热度阶段判断**（在性质标签后附注，判断现在追是早还是晚）：

| 热度阶段 | 板块近 5 日涨幅 | 板块涨停数量 | 含义 |
|---------|--------------|------------|------|
| 🟢 初期 | < 15% | 0–1 只 | 叙事刚启动，性价比最高 |
| 🟡 发酵中 | 15–35% | 2–3 只 | 主升段，追需确认板块不过热 |
| 🔴 过热 | > 35% | ≥ 4 只 | 已在派发阶段，慎追；L3 候选评分上限强制 -2 |

> 组合读法示例：「✅ 持续主线 · 🟢 初期」= 最优入场窗口；「✅ 持续主线 · 🔴 过热」= 主线仍在但追高风险大；「⚡ 脉冲热点 · 🔴 过热」= 直接跳过。

### L2 热度质量验证

**前置门槛 1（硬否决）**：成分股 5d 涨幅中位数 vs 板块指数，差距 > 5pp → 判定「权重法伪信号」，直接出局。

**前置门槛 2（集中度）**：Top1 成交占比 >50% 或 Top2 >70% → 判定「板块 = 单票行情」，降级走 stock-analyzer。

通过门槛的板块逐个标注：持续性（资金是否连续 3 周+ 净流入）/ 广度（上涨成分股占比）/ 催化回看 / 催化前瞻（event-calendar）/ 异动密度 / 链上拥挤度（仅 US）/ 北向资金方向（仅 CN）。

### L3 板块内候选性价比向量

质量阀门先过（流动性 / 市值 / PE 为负 / 停牌新股 / ST），再用 6 因子软打分排序，总分 ≥ 4 进候选，每板块取 3-5 只。详细打分表与各市场差异见 [references/l3-scoring.md](references/l3-scoring.md)。

### L4 收敛

跨板块去重，按总分排序取 Top 3-5，作为最终候选清单。报告末尾明确说：「建议对下列候选调用 stock-analyzer 做八维度深度分析：`stock-analyzer 分析 <CODE1>, <CODE2>, ...`」。

### L5 产业链外推

五类标准传导路径（上游设备/材料、下游应用/整机、同主题细分滞后、资金外溢、估值差套利）+ A 股额外 3 类（政策扩散、AH 跨市传导、连板情绪扩散）。每条路径必须有具体代码 + 反驳点 + L1 数据回测（4 档状态：🔥 已在动 / 🟡 跟随启动 / 🟢 还没动 / 🔴 反向走弱）。详细逻辑与输出格式见 [references/l5-extrapolation.md](references/l5-extrapolation.md)。

## 输出格式

完整模板见 [references/report-template.md](references/report-template.md)。报告骨架：

```
0. 本期主题发现（Tavily 热词 → 映射板块）
1. 多重信号确认的板块 Top 5（含背离列、集中度列）
2. 板块逐个解读（轮动性质 + 持续性/广度/催化/前置门槛结果）
3. 建议深度分析的候选（调用 stock-analyzer）
4. 单一信号板块（候补池）
5. 被前置门槛淘汰的板块（透明度记录）
6. 产业链外推（L5，标 ⚠️ 推断非事实）
7. 本期扫描的局限
```

## 输出调性

- **中性描述**："XX 板块近 5 日涨 +X%，成分股中位数 +Y%，资金净流入 X 亿，媒体集中报道 Y 事件"——不说"板块启动 / 主升浪 / 风口"
- **候选措辞**："符合性价比向量筛选的候选"而不是"值得关注的标的 / 优质标的"
- L1-L4 部分**只描述当前**，不在这一段说"下一个热点是 XX"
- L5 部分允许受约束的产业链外推，每条传导落到具体代码 + 列反驳点 + 用数据回测标"已在动 / 没在动"
- 被前置门槛淘汰的板块要显式列出来，展示"为什么没上榜"

## 什么时候答"不确定"

明确告诉用户**无法给出热点清单**，不要硬凑：

- OpenD 未连接 / 板块列表接口失败
- 当日是节假日 / 半日市（数据信号不足 1 个完整交易日）
- Tavily 配额打满 → L0 和 C 新闻验证都失败时，只给 A+B 双信号板块并标「新闻维度缺失，样本有限」
- 全市场 5 日涨幅都为负（系统性杀跌）→「当前市场无热点板块，属防御行情」，不强行推候选
- L1-L4 没识别到任何主热点 → 报告里直接写「无主热点可外推，跳过 L5」
- **A 股特有**：A 股交易时间为北京时间 9:30-11:30 / 13:00-15:00，非交易时段需说明「A股已收盘，数据为今日收盘截面」

## 常见陷阱速查

> 详见 [references/pitfalls.md](references/pitfalls.md)

- INDUSTRY 漏主题 → 必须并扫 CONCEPT
- 今日涨幅误导 → 用双窗口并集（5d + 10d）
- 板块指数骗人 → 成分股中位数校验
- 集中度 = 单票行情 → 直接走 stock-analyzer
- 美股蓝筹资金流返回 0 → 启用代理，不要判"无资金"
- PE 字段跨源不一致 → 首选 `get_stock_info` 的 `pe_ttm`
- 东财 f115 不是 10 日涨幅 → 10 日用富途 K 线计算
- 噪音板块污染排行 → NOISE_KEYWORDS 过滤（详见 [references/api-eastmoney.md](references/api-eastmoney.md)）
