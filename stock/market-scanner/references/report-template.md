# 市场热点扫描报告模板

## 场景路由

根据 L1.5 后门控早停判断结果，选择对应模板：

| 场景 | 触发条件 | 跳转到 |
|------|---------|--------|
| 完整报告 | 持续主线 ≥ 2 | [完整模板](#完整模板) |
| 精简报告 | 持续主线 = 1 + 强度够（4 周连涨 + 量能放大） | [精简模板](#精简模板) |
| 无主线 | 持续主线 = 1 + 强度不足 | [无热点模板](#无热点模板) |
| 停止追涨 | 持续主线 = 0 且大盘非🔴 | [无热点模板](#无热点模板) |
| 防御行情 | 大盘 🔴 | [防御模板](#防御模板) |

> 所有模板第 0 行固定：**今天能不能追**：<能 / 不能 / 等止跌（预计 N 个交易日）>

---

## 防御模板

```markdown
**今天能不能追**：不能（大盘🔴，系统性杀跌）。但红盘≠无做多侧机会：

- **抗跌观察池**：逆势翻红/创新高/回撤显著小于指数的强势股（带相对强度 pp）
- **低吸等待位**：原主线龙头的关键支撑位（等止跌确认，不接飞刀）
- **防御方向**：低波 / 高股息 / 必需消费（用 L3 向量打分，"跑赢板块"在防御里更稳）
- L5 外推跳过；不出追涨主线候选；空头机会不在本 skill scope
```

## 场景化调整

### 场景 1：用户指定单一市场

"只扫港股" / "只看美股" —— 砍掉另一市场章节，其余不变。

### 场景 2：用户指定单一板块追问

"AI 板块里有没有还没涨透的票" —— 跳过 L1 热度扫描，直接进 L3 候选排序。报告骨架：
```
### <板块名> 板块内候选扫描
**板块当前状态**：5/10 日涨幅、资金流、近期催化（简版 L2）
**候选列表**：L3 完整表格
**深度分析建议**：同主模板 "建议一键深度分析"
```

### 场景 3：市场整体防御 / 杀跌

L1 三重信号命中 ≥ 2 的板块 < 3 个时：
- **不硬凑 5 个板块**
- 输出："当前 <市场> 处于系统性调整 / 防御行情，满足三重信号的热点板块仅 <N> 个"
- 建议：
  - 跳到低波 / 高股息 / 必需消费类板块（用同一 L3 性价比向量打分，但换 4 因子里"相对板块动量"的解读 —— 防御行情里"跑赢板块"反而更稳）
  - 或告诉用户"更适合先做宏观 + 风险资产配置判断，热点扫描本期信号不足"

### 场景 4：某一信号维度失效

- **Tavily 配额用完** → 仅 A+B 两信号，主榜要求降到"命中 A+B"，主报告明确标注"新闻维度缺失"
- **OpenD 资金流接口失败** → 仅 A+C 两信号，性价比向量的"3 日资金"打分改为 0（中性），并在局限里说明
- **板块 API 返回空** → 整份报告降级为"热门个股扫描"，用 `get_capital_distribution` 跑全市场资金榜 Top 50 并按成分股所属板块逆向聚合

## 调性速查

- ✅ "X 板块 5 日涨 +8%，当日主力净流入 3.2 亿，彭博 / 路透密集报道 Y 政策"
- ❌ "X 板块正在启动主升浪" / "风口来了"
- ✅ "`HK.XXXXX` 在板块内涨幅仅 +2%（板块 +8%），PE 分位 25%，主力连续 3 日净流入"
- ❌ "这只票被低估值 + 跟涨滞后特征锁定，值得关注"
- ✅ "建议对下列候选调用 stock-analyzer 验证"
- ❌ "建议逢低买入" / "这是下一个热点候选"
