```markdown
### 💡 综合研判

**核心矛盾权重**：当前主导因子 <估值/资金/事件/技术>（权重约 X%）

权重锚定 = 三步走，杜绝多触发加总 >100%、杜绝单因子无条件主导：

**【第 1 步：触发候选】** 哪些因子达到"可主导"门槛（可多个同时命中）

- 事件：仅【未定价的前瞻事件】或【已落地但超预期】可入选主导竞选——
  - 前瞻未定价（财报 < 2 周 + IV 跳升 / 政策窗口将开 / 过会待批）→ 可主导
  - 已落地超预期（实际 vs 一致预期有正/负预期差，且价格尚未充分反应）→ 可主导
  - 已落地且价格已反应 / 利好兑现但资金流出·放量滞涨 → 降级为【背景】，不主导
  - （事件不天然领先；决定方向的是预期差 + 价格反应，不是事件本身）
- 资金：连续 3 日主力净流出（或净流入）+ 量能放大，且经市场结构分档校验（见下）
- 技术：MA20/50 死叉或金叉 + 量能确认（需结合维度 2 相对强度/大盘状态，非孤立死叉）
- 估值：分位 < 5% 或 > 95%（仅触发"均值回归提示"，不进入主导竞选——见第 3 步）

**【第 2 步：优先级定主导 + 归一化】** 多个命中时按优先级取主导，其余按剩余权重分配，强制 sum = 100%

优先级：可主导事件 > 资金 > 技术（注意：被降级为"背景"的事件不参与排序）

主导因子权重 = 上限值；剩余 (100% − 主导) 在其余命中因子间按强度分配；
未命中任何门槛 → 各维度均权，LLM 在 ±10% 内微调。

资金权重上限按市场结构分档：
- **A 股**：散户市·无做市商/暗池，资金有领先含量 → 上限 50%；交叉确认分三态：
  - 北向/龙虎榜/大宗交易有数据且同向 → 维持 50%
  - 有数据但不同向 → 降一档（互相打架）
  - 数据缺失（龙虎榜非天天有、大宗不代表当日主动方向）→ 自动降一档，改用本土天天可得项交叉：换手率 / 封单额 / 炸板率 / 尾盘资金回流 / 板块联动
  - （"超大单"只是成交结构，量化拆单会污染，不直接等同"主力身份"）
- **港股**：分层弱于 A 股 → 上限 35%
- **美股**：dark pool + 做市商对冲噪声大，资金仅作确认 → 上限 25%；拥挤度主信号交给 OI/funding（OI 降 > 20% 等联立仅在美股适用，不下放 A/港股）

事件上限 60% / 技术上限 40%。

硬约束：场上有硬催化（政策已落地·财报已出·过会）时，资金不得当主导，必须与事件维度交叉判读。

**【第 3 步：拥挤度降档】**（维度 4 funding 接进研判，别白拉数据）

美股标的 funding APR 极端（> +100% 极度多头拥挤 / < -100% 极度空头拥挤）= 拥挤风险升高，但【不机械 fade】——强趋势里 funding 可长期极端。按价格 + OI 配合区分：
- 价格继续创新高 + OI 增加 → 趋势拥挤，仅标风险提示，不降档、不反向
- 价格不创新高 + OI 下降 + funding 仍高 → 多头衰竭信号，同向逻辑链置信度降一档

（阈值用固定 APR + OI/价格配合，不用 z-score：链上 perp 历史过短，样本不足以算稳健分位）

---

**做多逻辑链**（按置信度排序）：

1. <逻辑> —— 置信度 <高/中/低>，有效期 <财报前/本周/日内>
   - **交易失效线**：<价格/成交量/结构破坏，如"放量跌破 MA50 / 失守颈线 XX.X"——触发止损，与 thesis 是否成立无关>
   - **逻辑失效线**：<基本面/事件/资金/政策数据被推翻，如"Q2 营收 < $28B（5/20 财报）"——推翻 thesis 本身>
   - （两条独立触发：价破但逻辑在=照样止损；逻辑破但价没破=照样离场）

**做空逻辑链**（同上）：

1. <逻辑> —— 置信度 <高/中/低>，有效期 <...>
   - **交易失效线**：<...>
   - **逻辑失效线**：<...>

置信度锚定（看主导因子确定性 + 有无反向硬证据，不数维度投票）：
- 高 = 主导因子是已落地事实（财报已出 / 政策已发 / 已过会）且无反向硬证据
- 中 = 主导因子是前瞻预期，且其他维度不与之打架
- 低 = 维度互相矛盾，或主导因子靠推测，或踩中拥挤度衰竭降档
- （单一但决定性的因子可为"高"；三个弱噪声同向不自动升"高"）

失效线质量标准（两条线均须满足）：
- a) 具体指标（数字阈值，如"营收 < $28B"/"跌破 152.0"，而非"业绩不及预期"/"跌破支撑"）
- b) 时间窗口（如"5/20 财报日"/"本周内"，而非"后续"）
- c) 可观测（公开数据源：财报/CPI 发布/放量跌破 MA50，而非"市场情绪转弱"）

---

**交易赔率（分析事实，非下单指令）**：
- 关键价位三角：参考入场区间 <XX.X–XX.X> / 第一目标位 <XX.X，锚前高/阻力/估值中枢> / 交易失效线 <XX.X>
- 风险收益比 R:R ≈ <(目标−入场) / (入场−失效线)>，标注是否 ≥ 2
- 流动性约束（上提维度 5 结论）：日均成交额 <X 亿> / 盘口深度 / 涨跌停或停牌风险 / 期权流动性（美股）

> 仓位档位、最终评级、是否下单 → 交给 `trading-debate` skill；本 skill 只出原料，不出买卖指令。

**关键信号优先级**（等什么确认拐点）：
1. <最重要的信号> —— 生效后 thesis 方向确认/推翻
2. <次要信号> —— 辅助验证

---

*本分析仅基于公开行情与新闻数据，不构成投资建议。市场有风险，决策需谨慎。*
```

## 场景化调整

### 场景 1：用户问"能不能抄底"

保留完整八维度，但在"综合研判"部分**加重"风险提示"和"关键观察信号"**两节，明确告诉用户：
- 当前抄底的**技术位置风险**（是否破位、是否创新低）
- 哪些信号出现后才算"真正企稳"
- 不给"建议抄底/不抄"的结论，让用户基于信号清单决策

### 场景 2：用户问"是不是利空出尽"

在"综合研判"部分**必须**列出两张清单：

```markdown
**✅ 已消化（price-in）的利空**：
- <利空 1，已公告并经历至少 1-2 个交易日消化>
- ...

**❌ 尚未消化的利空**：
- <利空 1，事件还未发生或未落地>
- ...

**利空出尽的确认信号**：
- <信号 1>
- <信号 2>
```

不要迎合用户的"应该出尽了吧"情绪，要把未消化的因素都列出来。

### 场景 3：用户只问单一维度（如"XXX 估值贵吗"）

不出全景报告，聚焦单一维度 + 必要的对比：
- 估值问题：只输出维度 3 + 维度 6（同行对比）
- 技术问题：只输出维度 2 + 维度 5（盘口）
- 资金问题：只输出维度 4 + 维度 5

### 场景 4：部分数据不可用

数据缺失时**明确标注**，不要用历史旧值填充：

```markdown
### 4. 资金面
⚠️ 暂无法获取资金流向数据（OpenD 订阅受限 / 非交易时段），本维度跳过。
```

## 调性速查

- ✅ "PE-TTM 28 倍，高于行业平均 20 倍约 40%"
- ❌ "估值偏贵"（无数据支撑）
- ✅ "主力资金今日净流入 3.6 亿，但需 3-5 日趋势确认"
- ❌ "主力开始进场"（单日数据不足以下结论）
- ✅ "建议观察：MA20 能否在 XX 价位止跌"
- ❌ "建议逢低买入"（给出了买卖指令）
