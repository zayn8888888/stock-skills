# v0.5 跨标的反思教训聚合

v0.3 反思机制是**单标的内**——存"我对 NVDA 这次错在哪"。v0.5 在这之上做**跨标的模式识别**——聚合多个标的的反思，找到"我对**这一类**股票一直犯什么错"。

## 设计动机

单标的反思的盲区：
- 对 NVDA 反思：低估了 Culper 做空报告的影响
- 对 AMD 反思：低估了财报后的股价回调幅度
- 对 TSM 反思：高估了产能扩张速度

单看每条都"言之有理"，但放在一起会发现：**这三条都是"高估半导体周期上行斜率"的不同表述**。这是**模式级错误**，需要更结构化的修正。

ai-hedge-fund 没有这个能力（17 大师独立投票，无反思）；TradingAgents 的 Reflection 是单标的事后反思。本 skill v0.5 是相对两者的**额外创新**。

## 触发场景

**自动触发**（推荐）：每次跑 trading-debate 阶段 8a（历史召回）时：
- 如果该 ticker 所属行业 / 主题已有 ≥ 3 条已反思的历史决策 → 自动跑教训聚合
- 把聚合结果作为额外上下文注入 PM prompt

**用户触发**：
- "我对半导体股的判断有什么模式问题"
- "复盘我所有 AI 概念股的决策"
- "我做空决策的胜率怎么样"

## 教训聚合分类法（4 种维度）

聚合时按以下 4 个维度做交叉切片，找到模式：

### 1. 行业 / 主题维度

把决策按行业归类（半导体 / 新能源车 / 互联网 / 金融 / 消费 / 医药 / 银行 ...），看每个行业的：
- 总命中率（评级方向 vs 实际 alpha 同向比例）
- 平均 alpha
- 反思中重复出现的关键词（如"低估周期下行"、"高估护城河"）

### 2. 评级方向维度

切分 Buy/Overweight vs Underweight/Sell：
- 看多决策胜率 vs 看空决策胜率
- 多空胜率差 > 20% → 存在系统性偏差（"我做多比做空准"）

### 3. 信心度维度

切分高信心（confidence ≥ 70）vs 低信心（< 70）：
- 高信心决策若胜率 < 60% → 过度自信问题
- 低信心决策若胜率 > 70% → 过度保守，不敢下注

### 4. 大师团一致性维度

切分大师团高一致（≥ 4:2）vs 分歧大（≤ 2:2）：
- 高一致情况下 PM 反向决策的胜率（衡量 PM 是否过度独立）
- 分歧情况下 PM 决策的胜率（衡量 PM 在模糊信号下的判断力）

## 教训聚合 Prompt 模板

```
你是交易复盘分析师，读以下 N 条已反思的历史决策，找出模式级错误（不是单次错误）。

历史决策清单：
{decisions_with_reflections}
（每条含：ticker, 行业, rating, confidence, 实际 alpha, 反思文本）

【4 维度切片要求】：

1. 按【行业/主题】聚合：
   - 列出每个行业的决策数 + 胜率 + 平均 alpha
   - 标记胜率 < 50% 或 alpha < -5% 的"差表现"行业
   - 提取该行业反思文本中重复出现 ≥ 2 次的关键词

2. 按【评级方向】聚合：
   - 看多胜率 vs 看空胜率
   - 差距 > 20% 时明确指出方向偏差

3. 按【信心度】聚合：
   - 高信心（≥70）vs 低信心（<70）的胜率
   - 找出过度自信或过度保守的迹象

4. 按【大师团一致性】聚合：
   - PM 与大师团一致 vs 分歧时的胜率
```

## 触发频率与刷新

- **新决策完成时**：仅在该行业累计已反思决策数 ≥ 3 时触发聚合
- **手动复盘时**：用户主动要求，无累计阈值
- **过期重算**：每 30 天重算一次（决策反思有时滞，新增反思会改变模式）

## 自检（v0.5 实现时）

- [ ] 聚合是否真的读了 ≥ 3 条已反思决策（不是 2 条凑数）
- [ ] 每个维度切片的胜率计算公式是否一致（避免一会按 alpha > 0 一会按 rating 方向）
- [ ] top_lessons 是否真的可操作（不是"要多注意 X"这种空话）
- [ ] 注入 PM prompt 后，PM 是否真的引用了教训而不是装作没看见

## 与 v0.3 的关系

| 维度 | v0.3 反思 | v0.5 教训聚合 |
|------|----------|--------------|
| 粒度 | 单标的单次决策 | 跨标的模式识别 |
| 触发 | 决策超 3 月 | 累计 ≥ 3 条已反思决策 |
| 注入 | 同 ticker 历史教训 | 同行业 / 全局模式教训 |
| 输出 | 2-4 句反思文本 | 4 维度切片 + top_lessons |

v0.5 **依赖** v0.3 的反思数据——v0.3 没跑过反思就没原料给 v0.5 聚合。

## 不允许的偷懒模式

- ❌ 用未反思的决策做聚合（必须 v0.3 反思已完成）
- ❌ 维度切片用了不一致的胜率公式
- ❌ top_lessons 全是"要小心 X"的空话
- ❌ PM 阶段 6 拿到教训装作没看见，原样输出决策
- ❌ 教训聚合在新决策完成后没刷新（陈旧教训误导）
